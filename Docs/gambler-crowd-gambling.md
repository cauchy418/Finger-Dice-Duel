# 赌徒：聚众赌博

赌徒完成一次行动后，最终手值为 **1** 时，可选择一名存活角色（包括自己），使其下个自己的回合必须用 **1d9** 代替正常运算。正常运算与命运赌博都可触发；恶之强运重掷后以最终结果为准。可不发动。选人不受攻击距离限制。

这是独立的技能标记，不是新增负面状态，不叠加；重复指定只刷新为一个下次回合。目标角色面板显示赌徒徽记、角标 1 和规则提示。施加时复用命运骰动画，并将标记变化写入目标的动画快照。目标阵亡前施加者阵亡不会撤销已施加的标记。

“下个自己的回合”按主行动机会计算：该回合若正常行动，点自己的手后只能开赌，掷点后照常选择攻击目标；若冻结、双手无法行动、双盾跳过或选择其他合法跳过路径，该机会结束时标记也到期。其他角色的行动和额外纯运算不消耗标记，额外纯运算不受该标记限制。自身指定自身不会追溯改变已经结束的行动。

骰子替代运算结果，后续效果仍使用目标自身职业与状态的规则，例如奉献之誓赌出 4 仍按其合盾规则处理。非赌徒只获得这一次被强制的赌博机会，不获得恶之强运，也不会因此进入赌徒之运的连续强制循环。赌徒原有的“上一次正常运算后下次必须赌博”独立保留；单次赌博可同时满足两种要求。

人类沿用角色选择弹窗，可选择目标或“不发动聚众赌博”。AI 在同一触发点比较各角色现有普通运算的质量：优先干扰有强攻击运算的敌人，或帮助没有有效运算的己方；没有正收益时不发动。UI、AI 和直接引擎入口共用标记及赌博结算。
