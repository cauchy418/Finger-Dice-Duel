# P1动画第一批与持续状态表现

2026-10-31。对应[总清单](skill-and-status-animation-list.md)。本轮复用已绘制素材完成程序动画，不新增角色技能规则。

## 物理挥击修订

剑／锤／棍主体由180放大到300；拳175、刺剑255，起手210。剑／锤／棍以靠近握柄的轴点旋转，从约−100°扫至38°；起手在来源手，主要挥击以目标附近握持点为轴，不再像投射物沿连线平移。弧形拖尾只在真实挥击出现；被取消时不会在目标处留下斩痕。拳、刺剑保持短促冲击，远程弓箭保持射击。

主要出手阶段由0.34秒调整为0.50秒，命中扩散由0.18秒调整为0.22秒；1／2／4倍速及跳过保留。

## 持续负面与角色效果

状态栏每个有效图标循环轻微呼吸；回合数、数值或状态描述发生变化时短暂高亮。角色周围使用对应火焰／霜、电弧、毒雾、光耀、暗蚀等小型持续效果；每名角色最多同时展示3层，其他层轮换，状态图标始终保留。死亡／清除后淡出，返回标题清空。当前荒野／星耀形态图案也循环轻动。

攻击落地、技能实际生效、持续扣血与元素反应时触发短高亮。抗性／易伤／免疫、奥术守御、气、标记、预兆、虚假生命、暗劲等复用同一持续框架，但保留各自原图与计数。这里的“高亮”是短脉冲，未加入全屏白闪；不会更改时长、额外触发伤害或随机决策。

规则仍以[RULES](../RULES.md)为准；后续制作优先按本表“专属深化”推进，而不是把资源图标的呼吸当作最终专属动画。
