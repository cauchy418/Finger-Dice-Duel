# AI技能启用与入口一致性

本次按所有58个子职检查AI构造入口、技能接口、选择策略及运行时与采样配置，目标是发现已实现策略被遗漏接入或默认关闭的情况。不会把实验开关一律开启。

## 检查范围

- 普通1v1／2v2／8人、身份局、双将、剧情自由战斗及召唤物AI。
- HandEffect与字符串选择键、角色能力接口、双将部件转发、分阶段人物／手选择及强制赌博。
- 保留教学脚本限制；实验性的全局投影与参数显式关闭仍可用于对照测试。

## 当前修正

生产AI通过统一入口明确启用破阵强袭和已验证的模式／角色参数。身份局保留原有集火口径，剧情自由战斗与相同普通模式一致；八人阵营采样同步实际运行时的集火配置。

双将中塑能学派须读取实际实现IMageState的部件，而非只检查外层双将容器，确保可判断和发动法术塑形。

全角色攻击／防守收集矩阵验证了257个合法答案，另用主副双序验证塑能、盗贼、太极与赌徒。技能抉择键和策略接口均追踪至实际选择路径；不会把按收益拒绝发动视为入口缺失。采样期间冻结运行时、测试及统计工具，所有模式复用同一程序集；如发生宿主原生中断，该模式从首局完整重跑，不拼接不完整结果。

## 实际发现

| 位置 | 遗漏与修正 |
|---|---|
| 剧情自由战斗 | 部分入口遗漏普通对战已采用的模式／角色参数，现由ProductionAi统一配置；教学脚本继续单独控制 |
| 八人阵营采样 | 集火开关与实际运行时不一致；本轮同步运行时配置，身份局保留自身原口径 |
| 双将塑能 | 外层容器识别导致备法、类型选择和消耗被跳过；改为对子职部件操作 |
| 普通／双将塑能AI | 第一次接受或拒绝答案未及时回写，后续可能再次随机决定；现在消费同一次显式答案 |
| 双将盗贼 | 偷窃可用性与自动执行只判断单角色，现查找真实子职能力 |
| 双将太极 | 零点触碰预览与执行未找到太极能力，现按同一部件判断 |
| 双将赌徒 | 主动赌博、重掷和强制循环的单角色判断阻断了子职能力，现共用部件查找 |

没有调整本轮角色数值或策略权重。角色策略质量与“技能入口是否启用”是不同问题，行为回归不证明某技能在任何局面都应发动。

## 验证与边界

最终功能回归1769项通过、0失败；243个UI脚本编译与Unity/NUnit条件编译通过。新增生产入口4项、双将赌徒7项、技能派发11项确定性回归，含58子职共257个合法预攻击答案，以及采样种子761708的盗贼强制赌博续接场景。统计工具8项测试通过。

被变羊和荒野形态暂停的原技能仍保持暂停；部件查找仅检查当前角色行为。教学脚本、实验用裸构造器及备用随机AI保留自己的配置；备用随机AI的破阵强袭概率0属于显式对照配置，正式运行与本轮采样使用生产贪心AI。

本轮没有新调角色数值或模式策略权重。胜率是固定AI在规定配桌与种子下的结果，不能把所有变化归因于某一项修复，也不构成最优策略证明。

全量采样还捕获并修复了种子4048400：双将赌徒把变化莫测的额外运算误转为赌博；现在该额外运算继续使用正常加法选择，强制赌博要求留给下一主行动。精确种子与双将双序、人类／AI流程均已纳入回归。正式报告只使用此修正后的完整重采数据，先前不完整轮次不入库。

## 正式采样

全部66,964局已按最终源码完整重采：1v1 33,060、2v2 26,448、双将4,256、八人阵营600、身份随机2,000、身份偏好600。发布样本游戏异常与模拟器强停均为0，六组种子顺序、出场分母和运行时偏好输入均核验。完整结果、平局与前后来源对比见[本轮报告](../Tools/Statistics/2026-11-11-ai-activation/README.md)。
