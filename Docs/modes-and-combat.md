# 模式与战斗细节

[返回索引](README.md) · 权限最高的规则原文见 [RULES](../RULES.md)。

## 一回合的完整流程

每人通常 **20 生命、左右各一只手**。入门模式从 1/1 开始；经典模式按 1d20 分配初始手值。普通手值为 1～9，太极等技能可产生 0。

1. 点自己的一只可用手，作为本回合的运算手。
2. 点另一名存活角色的一只可用手作加数；多人局可以用队友的手。通常不能用自己的手，魔术师等允许自加的技能另有例外。
3. 确认加数后，手牌先显示运算后的数字与手型；若结果为攻击，再选射程内的攻击目标；目标可以与提供加数的人不同。按界面提示完成主动技能、防御技能或治疗选择。

**普通运算只改变运算手，提供加数的手不变；诡诈换位等交换技能除外。** 结果取个位，0 变 1。例如 3＋5＝8、9＋9＝8、1＋9＝1。

| 结果 | 基础效果 |
|---|---|
| **4 / 6 / 8** | 发起基础伤害为 4 / 6 / 8 的攻击 |
| **9** | 自己回复 9 点生命，不超过上限 |
| **5** | 这只手合成一面完整护盾 |
| **1 / 2 / 3 / 7** | 仅改变手值，不产生基础效果 |

效果只在运算产生结果时结算一次：手停在 9 不会每回合自动回血，初始分配的 5 也不是已经合成的盾。角色技能可改写数字效果，例如奉献之誓的 4/6 合盾、巨人道途的 5 攻击、狂战士道途的 9 攻击。

### 伤害、护盾和距离

普通攻击先按技能处理基础伤害，再计算 **max(0，基础伤害＋攻击加成−目标防御加成)**，最后按相关状态、防御技能及同类型免疫／易伤／抗性结算。正防御减伤、负防御会增加承伤；固定伤害等技能有自己的例外。

例如基础 4、攻击 +1，对防御 +1 的目标造成 4 点伤害。勇士双手和 10 时，先将基础 4 乘 1.5 变 6，再计算攻防。

- **护盾**：完整盾可挡一段攻击伤害，随后破碎；多段攻击逐段处理。主动使用完整盾那只手运算，会先自行碎盾。盾牌专用手型为五指并拢的 5。
- **距离**：按存活角色座位环的最短距离计算，阵亡者移出环。攻击要求距离不超过射程；**∞** 表示不受通常射程限制，状态限制仍需遵守。
- **加数与攻击目标分开**：能借到一只手的数字，不代表能打到这只手的主人。队友可以提供加数，也可以成为合法攻击目标，选目标时应注意。
- **跳过与放弃**：冻结、双手都无法运算等情况可跳过；部分技能允许主动跳过。没有合法攻击目标时，可放弃攻击并完成本次行动，已经产生的运算结果保留。

生命归零即阵亡。一轮指存活角色各经过一次正常行动；通常模式上限 50 轮，身份局 80 轮，跳过也会推进正常回合流程。

### 界面操作

主菜单已接入各模式选将、先攻投骰、战斗、角色图鉴和秘法手册。自由选将先点职业大类，再选子职。抽将模式直接亮出本局候选。图鉴每页 12 名，支持职业与阵营组合筛选。对局右上角的“返回”直接回到玩法菜单或剧情关卡列表。“再来一局”可回到本局选将页。多人对局的胜利面板展示获胜阵营的原角色，包括已阵亡的成员。点击右上角的“战斗记录”可展开记录。姓名旁的状态图标和形态提示可悬停查看。

技能需要指定手时，直接点战场上高亮的手牌；指定角色时，使用角色候选按钮。元素、招式、形态等选择仍用对应选项，可放弃的技能保留退出按钮。

奉献之誓的守护之誓要求自己持有完整盾牌，且受击角色在自己的攻击范围内；代挡造成自己的盾破碎时，仍触发卫护斩并选择冲击目标。完整盾、碎盾与太极使用新版手绘标记。战斗已接入基础攻击动画：选目标时起手，确认后挥击／飞行并按段展示格挡、闪避与伤害；播放时可切换 1／2／4 倍速或跳过。动画覆盖范围见[动画进度](animation-p2-p3-progress.md)。

主界面 **设置 → 背景音乐** 可开关配乐并自动保存，战斗音效保留。配乐随普通战斗／剧情终战切换；任一非召唤角色半血后渐入额外战鼓，详见[音乐与音频](music-and-audio.md)。

## 模式规则

| 模式 | 基本玩法 | 胜负与上限 |
|---|---|---|
| **剧情模式** | 边境哨站、法师高塔、残旗战场各十战，学习基础、魔法与多人协作 | 指定演练后接受经典实战；各章终战按对应职业选角，真实获胜通关 |
| **1v1** | 各选一名子职，轮流运算、进攻与防守；有入门和经典两种开局 | 对手阵亡即胜；50 轮到限比生命，相同平局 |
| **2v2** | 四人环形战场，1 与 4 一队、2 与 3 一队；借队友数字，结合治疗、射程和集火 | 敌队全灭即胜；50 轮到限比全队生命总和，相同平局 |
| **双将对决** | 娱乐模式 1v1，每人同时拥有两名同阵营子职的技能 | 与 1v1 相同，50 轮到限比生命 |
| **8 人阵营混战** | 守序／中立／混乱三队，人数 3/3/2；可选单将或双将 | 只剩一个阵营即胜；50 轮比阵营生命总和，并列平局 |
| **8 人身份对局** | 1 主公、2 忠臣、4 反贼、1 内奸；隐藏身份、不同胜利目标与击杀奖惩 | 按身份目标判胜；80 轮到限平局 |

### 剧情模式

四章共40关，各十战（含终战）：边境哨站→万象回廊→法师高塔→残旗战场。先选章节，再从滚动列表选关，各章使用独立背景。

边境哨站从无特殊技能的重甲战士（攻+2／防+2）开始，实操6点攻击、2点受伤、合盾与回复，再学战士子职与经典先攻。万象回廊使用术士和塑能法师学习十种魔法伤害、免疫与十一条元素反应。高塔聚焦法师技能、持续抗性与奥术守御，并加入剑咏者。残旗战场学习借队友／对手手值、援护及多人协作。

每关最多10句教学提示，可上一页／下一页／回到当前；翻页不回退战斗。正常技能选项全部显示，只高亮和启用本步指定项。教学阶段的操演护持使指定角色最低保留1生命，幽影首次致命示范除外；观摩消耗正常行动，NPC仅在自己合法回合调数与有限整备。

教学全部结束、动画播放完后，中央提示“接下来进入实战试炼，对手会恢复至最佳状态。”点击进入实战才清理、回满存活敌方并恢复公开起手及能力；死人不复活、队伍与换位保留。玩家及存活同袍保留实际状态和资源，正常尝试回复6；幽影课另返还坟冢之力一次。实战正常AI，可失败，另有完整50轮预算。

实战中可在指引面板点击“回看指引”，用上一页、下一页和“回到当前”翻阅。“再次试炼”也保留本关的指引。

第五战和四章终战直接真实经典先攻，不覆盖骰点分手。终战分别限战士／术士／法师／圣武士，残旗终战为经典2v2。实战实际结束后先留战场，点击右侧“试炼结束”才打开总结。失败可“重新指引”或“再次试炼”；后者保留本次实战起点，不重复补给。退出后的半局不续存，旧进度与访问权按稳定关卡ID兼容迁移。

[逐关设计与数值](Adventure/four-chapter-v3/README.md) · [实机与回归验收](../Art/Integration/campaign-v3/README.md)。历史剧情胜率不代表新版难度，本轮未重采胜率。

### 1v1 与经典先攻

入门固定困难 AI，双方从 1/1 开始。经典演练允许玩家选择双方角色。经典挑战各给玩家与 AI 发 6 名互不重复的候选，玩家选自己，AI 随机选一名。选将结束后双方各投 **1d20**，决定初始手值与先手。

| 骰点 | 初始手值分配 |
|---|---|
| 2～18 | 两只手各为 1～9，总和等于骰点；例如 8 可选 1/7、2/6 等 |
| 1：大失败 | 由对手替自己自由指定两只手 |
| 19：小成功 | 至少一只手是 9，另一只任意 1～9 |
| 20：大成功 | 两只手各自自由选择 1～9 |

点数小的先分配，大的后分配并先行动；同点同时分配，双 1 则同时替对手指定。后决定者能看到先前确定的手值。**初始数字不会直接发动攻击、回复、合盾或潜行。**

### 2v2 的协作与站位

座位按 1→2→3→4→1 形成环，队友相邻，初始对角距离 2。入门可选座位，固定困难 AI；经典由四人投骰定座位：比较两队最大骰点，再比最小骰点，较大的一队坐 1 与 4，其余坐 2 与 3，仍同则随机。

经典演练可自选自己和队友，对手随机。经典挑战给两队各发 8 名互不重复的候选，玩家为自己与队友各选一名，AI 从自己的候选随机选两名。

经典手值通常按 **4→3→2→1** 依次分配；大失败先由配对对手代选，大成功最后自选，1 号位先行动。队友阵亡后仍可继续战斗，死亡座位移出距离环。配合可以是给队友治疗，也可以是保留让队友容易凑出攻击／合盾的手值。

### 双将怎样组合

两名子职必须不同，并同属 **守序、中立、混乱** 中的一类。双将人机演练可自由选自己的主副将，AI 随机搭配。挑战给双方各发 6 名互不重复的候选，各从自己的候选中配对。当前守序 18 名、中立 20 名、混乱 19 名，共 **514 种无序组合**，主副顺序可能影响技能优先级。

八人阵营混战先从 8 张背面牌里翻出所属阵营，再亮出角色牌。每席获得 5 名同阵营候选，八份候选互不重复。单将选一名，双将选两名。身份对局先翻身份牌，主公亮 8 张角色牌，其余座位亮 6 张，候选池也互不重复。

| 合并项目 | 规则 |
|---|---|
| 攻击、防御加成 | 两名子职相加 |
| 生命上限、射程、攻击段数 | 取两者中较大值，不相乘 |
| 技能 | 独立触发的技能共同保留；数字改写按各自负责的数字处理 |
| 同一步骤发生竞争 | 按主将优先等对应规则处理；同阵营不代表所有效果可无条件叠乘 |
| 形态 | 形态独立选择与解除；月亮属混乱、星辰属守序，当前不能互相组成双将 |

例如魔术师＋巨人道途由魔术师提供自加能力：2 是攻击，4/6/8 无效果，5 两段攻击，9 两段回复。完整结算例外见 [RULES 双将规则](../RULES.md#827-双将模式)。

### 8 人阵营混战

三队人数 3/3/2，哪队为 2 人每局随机。单将使用 8 个不同角色；双将每人带两名同阵营子职，尽量不重复角色。场面按环形距离计算，敌方阵营是主要进攻目标。

直接攻击击杀敌方后，击杀者额外行动 X 次，X 为被击杀阵营剩余人数；击杀同阵营角色，则从下家开始，其他阵营的存活角色各额外行动一次。额外行动不推进正常轮次，奖惩可嵌套；中毒、燃烧、太极反弹等不计入此击杀奖励。

### 8 人身份对局

战斗中可点击未公开座位左上角的「？」或带「猜」字的徽记，标记、修改或清除自己对该座位身份的猜测。角色阵亡或身份因规则公开后，牌桌显示真实徽记。主公抽签时用主公徽记，进场后随所选角色的阵营显示为明主、霸王或暴君。点击主公徽记可查看基础加成、称号规则和当前加成数值。

| 身份 | 人数 | 目标与关键特点 |
|---|---:|---|
| 主公 | 1 | 与忠臣共同消灭反贼和内奸；始终公开身份 |
| 忠臣 | 2 | 保护主公，与主公共同获胜 |
| 反贼 | 4 | 击败主公；身份终局分支按下文结算 |
| 内奸 | 1 | 最终独自存活；亮身份后可能转入对反贼的终局 |

人类在 AI 练习中随机获得身份，自己可见；主公始终公开，其他身份通常阵亡后公开。主公生命上限 +5、攻防各 +1，另按阵营获得存活同阵营人数驱动的称号增益：守序加防、中立加攻、混乱加生命上限。

界面按存活角色的实际阵线计数：开局主公／忠臣各 2 名队友、5 名对手，反贼 3／4，内奸 0／7。只有当前已知身份关系的座位才标“队友／对手”，未知身份只显示座位；计数不揭示隐藏身份所在座位。

内奸亮身份时本体生命上限 +5、回复 5、攻防各 +1。主公属于最先阵亡的三人时，反贼立即胜；内奸亮身份后主公死亡且仍有反贼，会清除忠臣并转为内奸对反贼。无反贼时主公死亡，有忠臣则反贼胜、无忠臣则内奸胜。击杀反贼可获得按剩余反贼数计算的额外行动，主公误杀忠臣会让存活反贼依次行动。详细身份优先级见 [RULES](../RULES.md#19-8-人身份对局)。

## 伤害与状态

### 13 种伤害类型

所有攻击都有类型。类型影响抗性、状态和元素反应，**魔法伤害同样计算攻防**，除非技能明确无视或固定伤害。表中状态是具有对应附加能力时的通常结果；光明领域的光耀攻击以专属圣光替代通常目盲。

| 类别 | 类型 | 通常效果或用途 |
|---|---|---|
| 物理 | 挥砍 Slashing | 刀剑斩击等；不自动附状态，流血由具体技能赋予 |
| 物理 | 钝击 Bludgeoning | 钝器、掌击等；不自动附状态 |
| 物理 | 穿刺 Piercing | 箭矢、刺击等；类型本身不等于穿盾 |
| 魔法 | 雷鸣 Thunder | 附残响，限制攻击距离；重复命中残响可触发眩晕 |
| 魔法 | 强酸 Acid | 附强酸，降低防御 |
| 魔法 | 毒素 Poison | 附中毒，回合开始持续伤害 |
| 魔法 | 光耀 Radiant | 通常附目盲，限制可借用的手 |
| 魔法 | 暗蚀 Necrotic | 附腐朽，阻止回复 |
| 魔法 | 火焰 Fire | 附燃烧，回合结束持续伤害 |
| 魔法 | 寒冷 Cold | 附覆霜，削弱运算；与覆霜／潮湿联动冻结 |
| 魔法 | 闪电 Lightning | 附感电，影响目标和相邻角色 |
| 魔法 | 力场 Force | 穿盾、无视正向防御、不可闪避；不附通常状态，取消／转移等按技能规则处理 |
| 魔法 | 心灵 Psychic | 50% 附恐慌、50% 附震慑，持续 2 回合 |

所有由攻击附加的计时负面状态按每段攻击独立计算：最终附加时长 = max(0, 基础时长 − 格挡扣减 − 对应抗性扣减)，格挡和抗性各最多扣 1。通常 2 回合变为：正常 2、仅格挡 1、仅抗性 1、格挡＋抗性 0；龙族血脉在再次附加已有状态时延长剩余时长1回合。0 回合不施加、不刷新，也不移除已存在的同名状态。多段按命中顺序附加／刷新：第一段挡下附 1 回合，第二段正常命中刷新为 2 回合。伤害按原分段规则处理，不因记录状态而重复扣血。闪避、潜行或取消均未命中，不附状态；类型免疫也阻止对应魔法状态。流血、卓越战技、魅惑、恐慌等攻击附加同样扣时长，圣光、剑歌、战争祝福、醉拳、神佑医者及思维之盾等非负面状态技能效果不扣时长，完整分类见[格挡定义](combat-defense.md)。

### 22 种负面状态

通常持续 **目标自己的 2 个回合**，不是全场行动两次；同种再次施加只刷新时间，不叠加强度。龙族血脉的对应状态为 3 回合，技能另有说明时优先。

| 状态 | 对玩法的影响 |
|---|---|
| 残响 | 只能攻击距离 1 的角色 |
| 强酸 | 防御 −2 |
| 中毒 | 自己回合开始受 2 点毒素伤害，不可抵挡 |
| 失明 | 攻击未失明角色时，每段伤害在攻防计算后减半、向上取整；不限制借数距离，与目盲独立 |
| 目盲 | 只能借距离 1 以内角色的手作加数；合法自加仍可用 |
| 腐朽 | 不能回复生命 |
| 燃烧 | 自己回合结束受 3 点火焰伤害，可被盾／闪避／太极处理 |
| 覆霜 | 运算结果减半、向下取整，最低 1；到期后附 2 回合潮湿 |
| 感电 | 自己回合开始，自己与环上相邻角色各受 1 点闪电伤害，可被防御机制处理 |
| 恐慌 | 攻击 −2，且不能攻击施加者 |
| 流血 | 攻防各 −1；自己回合开始失去 1 生命，不可抵挡 |
| 潮湿 | 运算结果 −1，最低 1 |
| 冻结 | 无法行动，通过跳过完成回合 |
| 震慑 | 不能攻击，但仍可完成其他合法操作 |
| 跛脚 | 攻击距离减半，最低 1 |
| 倒伏 | 受到的伤害 ×1.5，向上取整；固定伤害等例外按技能处理 |
| 魅惑 | 由 AI 随机选择合法行动 |
| 失能 | 攻击伤害归 0，攻防加成和追加伤害也不再扣血；仍保留攻击效果 |
| 眩晕 | 本次运算结果无效，不触发技能 |
| 束缚 | 每个自身回合随机一只手不能主动运算；仍可被借作加数，不解除原有技能锁 |
| 油腻 | 运算后 50% 概率倒伏 2 回合；火焰命中时清油腻、伤害 ×1.5，照常附燃烧 |
| 耳鸣 | 攻击与持续状态伤害 ×1.5，不能合盾或回复；免疫雷鸣伤害。可与易伤叠加，固定伤害规则优先 |

覆霜／潮湿会改变最终结果及对应效果：例如原本算出 9，覆霜使其变 4，就按 4 的效果处理。中毒、燃烧、感电的持续伤害不会反复给自己追加同一状态。

束缚本回合的受限手固定，下一自身回合重新随机；与另一手被锁等情况叠加时，可能需要跳过。油腻只在完成运算后判定，跳过、偷窃、赌博不触发；巨龙座的额外纯运算不触发数字效果。油腻触发的倒伏保留两个后续自身回合。

### 三种角色状态

| 状态 | 作用与持续方式 |
|---|---|
| 圣光 | 清除并阻止其他状态，含剑歌与战争祝福，以及非永久抗性／易伤／免疫；回合开始失去 1 生命、回复减半。通常 2 个自身回合；战斗激励和奥术守御等独立资源不受影响 |
| 剑歌 | 元素攻击、攻防 +1；后续自身回合须攻击、合盾或实际回复维持，无固定倒计时。圣光立即清除并阻止进入 |
| 战争祝福 | 攻防 +1；9 可选择照常回复或改为 9 点基础伤害攻击，普通运算、赌博与有效偷窃均支持。持续目标自己的 2 个回合，不叠加，重复施加刷新 |

角色状态不等于全是增益；生命领域仍可净化圣光，治疗保留战争祝福与剑歌。秘法手册在“状态一览”中分组列出这三种状态。

### 十一条元素反应

| 本次伤害＋已有状态 | 命中后的反应 |
|---|---|
| 雷鸣＋残响 | 清残响，附 2 回合眩晕 |
| 寒冷＋覆霜／潮湿 | 清除这两种状态，附 2 回合冻结 |
| 寒冷＋冻结 | 伤害 ×1.5，保留冻结，不附覆霜 |
| 寒冷＋燃烧 | 清燃烧，伤害 ×1.5，不附覆霜 |
| 火焰＋覆霜／潮湿 | 清除这两种状态，伤害 ×1.5，不附燃烧 |
| 闪电＋潮湿 | 伤害 ×1.5，保留潮湿，照常附感电 |
| 强酸＋中毒 | 照常附强酸，并将原中毒刷新至 2 回合 |
| 毒素＋强酸 | 照常附中毒，并将原强酸刷新至 2 回合 |
| 火焰＋油腻 | 清油腻，伤害 ×1.5，照常附燃烧 |
| 闪电＋残响 | 残响刷新 2 回合，附耳鸣 2 回合，照常附感电 |
| 雷鸣＋感电 | 感电刷新 2 回合，附耳鸣 2 回合，照常处理雷鸣原有反应 |

反应只在命中后触发；盾挡／太极减免仍算命中，闪避／取消不算。反应增伤在常规伤害上乘 1.5 并向上取整。火焰同时遇到油腻与覆霜／潮湿时，优先只清油腻、增伤一次并附燃烧，保留覆霜／潮湿。强酸／毒素与闪电／雷鸣互刷不额外增伤，本击新附的耳鸣从后续伤害生效；同类型免疫会阻止本次魔法附加状态与元素反应，不清除已有状态。心灵的概率状态属于伤害类型效果，不另列为元素反应。

### 抗性、易伤、免疫与角色标记

| 项目 | 作用 |
|---|---|
| 抗性 | 对应类型伤害减半，向上取整；攻击附加的负面效果时长 −1；永久抗性不随攻击消耗 |
| 易伤 | 对应类型伤害 ×1.5，向上取整；13 种类型各自独立 |
| 免疫 | 对应类型伤害为 0；魔法类型还阻止本次附加状态与元素反应，不清除已有状态；物理免疫不阻止技能流血 |
| 防护学派可授抗性 | 持续至施法者死亡或再次赋予；仅物理整组（挥砍／钝击／穿刺）、雷鸣、强酸、火焰、寒冷、闪电六项；不能授心灵／力场／毒素／光耀／暗蚀抗性 |
| 奥术守御 | 护盾与抗性后、扣血前吸收；使用即全部清空，点数显示在图标上 |
| 气 | 单武僧初始2、双武僧初始4，共用上限6的资源池；正常行动后双手相同回 1 气；0 点仍显示 |
| 暗劲 | 散打宗渗透劲施加，仅原施加者后续命中引爆半伤真实伤害；无倒计时，不叠加 |
| 猎人标记 | 显示在被标记者旁，由对应猎人的攻击消耗；多来源时角标表示来源人数 |
| 孢子生命 | 一体共生获得10点，先于虚假生命吸收伤害，溢出正常结算；无期限、不叠加 |
| 荒野充能 | 单德鲁伊2、月光3，双德鲁伊初始相加；孢子回充最高恢复到初始总量 |
| 虚假生命 | 妖魔将溢出治疗转成的绿色防护，最多 10 点；伤害先扣它，角标是点数，净化／圣光不移除 |
| 逸闻记录 | 记录图标显示已收集数／9；悬停列出具体数字与成长次数。集齐可选择成长，也可保留作减伤消耗 |
| 咒剑诅咒 | 目标旁显示来源与剩余回合；每段攻击加伤仅属于施咒者 |
| 变形 | 羊头像与剩余回合；形态生命独立显示，原技能暂停 |
| 奥法武器 | 显示待用元素，下一次攻击发起即消耗；剑歌与战争祝福另见角色状态 |
| 仇敌誓言 | 显示来源，无固定回合数；区别于咒剑的两回合诅咒 |
| 咒缚幽灵 | 显示召唤归属及永久保护；占位计距，召唤者死亡即消失 |
| 德鲁伊形态 | 面板右侧显示 4 种荒野／3 种星耀形态，当前高亮；是角色形态，不占上述负面与角色状态名额 |

防护学派授予的持续抗性、塑能待用类型自带抗性不会随受击消耗；圣光仍清除并阻止。

同类型免疫优先；没有免疫时先易伤、再抗性，分别向上取整。例如 5 伤 → 易伤 8 → 抗性 4。一次攻击落地后，全部临时抗性、易伤、免疫一起消耗，即使被免疫或屏障减至 0；整次多段攻击共享这些效果，完全盾挡／闪避／取消不消耗。生命领域净化也清除易伤，免疫作为正面保护保留；圣光清除并阻止临时保护与易伤。新增易伤／免疫为通用状态接口，没有额外赋予现有角色新能力。
