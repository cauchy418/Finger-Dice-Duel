# 知识领域规则与接入

## 牧师·知识领域

守序中立，攻0／防−1、距离∞；距离1以内钝击，超过1穿刺。牧师共同回复规则照常生效。

- **岁月知识｜被动技能**：正常加法运算进位后，获得1层知识祝福；纯运算不触发技能。
- **知识赐福｜被动技能**：回复给目标1层知识祝福。
- **知识祝福｜角色状态**：各来源层数相加，保留至攻击。整次攻击消耗全部层数；普通攻击命中／盾挡后，独立追加等层力场伤害，并附2回合困惑。多段只追加一次；闪避／取消不造成追加伤害。力场免疫阻止追加伤害与困惑，圣火清除并阻止祝福。
- **困惑｜负面状态**：加法运算的和达到10及以上时，结果改为1；预览与实际执行共用规则。

追加力场为独立伤害，不重复计作发起攻击，不二次触发征服成长等攻击事件；照常处理对应伤害防护和困惑附加。祝福标记角标为层数，不是回合。生命领域净化保留知识祝福。
