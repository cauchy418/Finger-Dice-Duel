# 净化领域实现与验证

采用 writing-plans 与 test-driven-development 流程，按已确认规则实施。

## 规则

净化领域维持牧师职业面板0／−1、距离∞。普通攻击改为固定5点火焰伤害，穿透火焰抗性与免疫；命中附圣火和灼伤各2回合，格挡／抗性对负面状态的时长扣减仍按公共规则。免疫仍阻止攻击附加状态，延续公共穿透口径。

圣火保留燃烧、灼伤、目盲，清除并阻止其余状态；抗性／易伤／免疫暂停生效，仍按自身期限计时，未到期者在圣火结束后恢复。保留回合开始失去1体力，回复量按普通规则。独立资源如奥术守御与战斗激励不清除。

灼伤为负面状态：每次实际回复后，立即受到实际回复量一半的火焰伤害，向上取整；无实际回复不触发。伤害沿用状态伤害的生命、防护和胜负结算，不重新附加状态。

打出9时可照常回复自己，或选择其他存活角色回复9并附2回合圣火。目标通过统一角色选择按钮展示；AI按敌友、可回复量与清除状态的收益选择。
