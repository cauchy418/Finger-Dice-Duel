# 第三章：残旗战场·八战 — 誓言与追击

2026-10-30，**已实现**，全局编号28。公开2v2，玩家席位1为复仇之誓，20生命、攻0／防0／距1；同袍4，对手2／3。三个独立演练。[共同要求](chapter-03.md)。

## 一：标记改变伤害，不改变距离

玩家1／2，教官甲席位2为3／3、20生命、防0，乙席位3为2／2。玩家本局首次自身回合进入真实“仇敌誓言”请求，指定甲；再用左1+甲左3=4攻击甲，造成4+1=5，20→15。

另开对照样本，重置相同数值，首次选择远处乙为仇敌；仍用同样算式攻击邻近甲，只造成4−1=3，20→17。远处仇敌不会因此进入普通攻击范围。同场仅一名仇敌，不能自己标记自己；教程不鼓励标记队友。

## 二：改标后碎盾，纯运算不出招

重建玩家完整左5盾／右2，甲1／3，乙2／2，同袍1／1。玩家首次自身回合标记乙，正常行动用右2+同袍右1=3，无效果，保留左盾。甲接着用左1+玩家右3=4攻击玩家。

来袭时“誓言转移”的改标／保留都显示，高亮改标到甲。甲破坏玩家盾，0生命伤害；因为破盾时甲已是仇敌，触发“复仇之魂”。接受／放弃均显示，指定接受；点击玩家已破盾左5，再点同袍左1，结果6。

这次6只改变手值，**不进入攻击选择，不附状态，不合盾、不回复、不增加一次正常回合，不单独推进持续时间**。玩家为6／3、仍20生命；沿原来袭攻击与正常轮序继续，不抢走下一个人的回合。普通攻击破盾与主动破阵强袭都可触发，每碎一面盾一次；本样本只展示一面。

## 三：同袍击杀，也可以更换仇敌

重建玩家2／1、20生命；甲席位2为4生命、无盾，乙席位3左3、20生命；同袍席位4为距离2弩手，1／2、攻0／防0。玩家首次自身回合标记甲，用右1+同袍左1=2，无攻击。甲、乙明示休整。

同袍左1+乙左3=4，跨距离2攻击甲，实际4伤害击杀。仇敌死亡请求中选择乙，即使击杀者不是玩家也可改标；不要求玩家再次攻击尸体。甲死亡移出距离环，玩家1与原席位3的乙现在相邻，关系仍为对手。

玩家下回合左2+同袍右2=4，攻击新仇敌乙，造成5，乙20→15。原座位身份不重排，甲的手不能再作为加数；只按存活环重新计算距离。

## 完成与验收

强制选择包含初始化、改标／保留、接受／放弃、手牌点击和死亡重选；正常相反选项不隐藏。标记图标跟随角色而非固定席位，死亡后目标列表更新且徽记完整。三个样本完成后留战场，点击“试炼结束”。
