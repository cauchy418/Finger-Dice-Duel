# 第二章：法师高塔·终战 — 高塔的回声

2026-10-26，**设计待实现**，全局编号20。本关是真实自由对战，允许失败。以下NPC数值是首版设计，不代表已经过胜率验证。

## 选角与开场

只开放**法师职业的全部9个当前子职**：咒法、塑能、防护、惑控、死灵、预言、幻术、变化、剑咏者。剑咏者虽未在本章单独授课，仍作为法师合法选择，选角详情可查看完整技能。初战的战士·奥法骑士不在法师池中。

流程：点终战→法师大类→选子职／查看对手→典籍开场→真实双方1d20→合法手值分配→自由实战。大点先行动、小点先分配、同点处理沿用经典规则；解释页可回看，不修改骰点。

典籍：“我能把每一种法术写在纸上，却不能替你决定下一步。塔顶留下的，是一位法师的回声。让它看看，你究竟读懂了多少。”

## 对手：法师幻影

| 项 | 首版配置 |
|---|---|
| 稳定NPC ID | `mage_tower_phantom`，只用于冒险 |
| 生命 | **32/32** |
| 攻击／防御 | **0／0**，不隐藏随阶段增加的数值 |
| 距离 | **∞** |
| 普通攻击 | 强酸，沿用4/6/8；命中按规则附强酸2回合 |
| 本场永久抗性 | **火焰、寒冷**，每次相应伤害减半向上取整 |

| 专属技能 | 汲能回路，见下文 |

这些属性在选角前可见，战斗中显示对应图标及“本场永久”；与第四战的一击临时效果区分。禁止靠攻击落地后偷偷重加来伪装永久，禁止用召唤物身份绕过显示或胜负规则。

## 专属技能：汲能回路

幻影**每累计3次普通攻击实际造成生命伤害后**，按正常治疗规则回复3生命，然后计数归0。进度0/3～2/3在名字附近的NPC说明或状态提示中公开显示，使用原恢复图标／文字，不占掉法师角色的技能按钮。

- 每整次攻击最多记1次；多段不多记。只由幻影本人对玩家造成实际生命伤害计数。
- 被盾完全挡住、闪避／取消、免疫、屏障全吸收、失能0伤、只消耗虚假生命不计。持续状态伤害、反弹、额外特殊攻击不计。
- 到3时若腐朽阻止回复，实际回复0，计数仍归0；满血不溢出成虚假生命。没有状态净化、免控或无敌阶段。
- 变羊期间该NPC技能暂停，羊的攻击不积累；解除保留此前进度。死亡后不靠回流复活。

这给死灵的腐朽、惑控的失能与预言的行动无效等提供明确反制价值；不靠强制让玩家受伤来展示技能，也不要求每局都触发。

## 战斗与AI

无固定演算脚本、无安全休整、无保命血线。AI走合法运算、攻击／合盾／回复与已有目标评分，不读取玩家隐藏选择或覆盖玩家技能答案；可识别自身回路及当前真实伤害类型，避免把0伤当回流进度。

32生命与两项抗性使其比哨站骑士更耐打，但玩家仍有普通物理、力场、暗蚀、雷鸣、强酸、闪电、光耀、心灵等路径；不迫使所有法师只能选某一个元素。预览和AI不可为了“难”每次自动抵抗控制、每轮恢复免疫或改玩家数字。

初版不额外加入“控制免疫／受伤自动净化／每轮换免疫”，以免刚教会的预言、惑控和变化在终战失效。普通强酸给出的降防要能被正常控制、净化规则与到期处理。

## 胜负与重试

玩家击败幻影或按50轮规则获胜即第二章通关；失败／平局不写关卡或章节胜利，旧胜利记录不被后续失败清除。可同子职重投，或回法师选角更换子职；重试清32生命、永久属性、回路进度和所有临时状态后重新建局。

胜利页：“你已经分清力量的形状，也学会了让它失去方向。典籍合上最后一页，高塔仍向你敞开。”提供重试、重新选法师、返回章节。第一章、竞技、双将和已有阵营不受新NPC影响。

## 实现后验收与难度校准

必须覆盖9个法师子职均可选、能发起合法行动且技能可用；永久修正提示与真实持续一致；毒素免疫挡状态但不清旧状态；腐朽阻止回流；失能0伤不记回路；变羊暂停技能；死亡不复活；投骰、重试、退出清理和存档隔离。

后续先用每子职至少200个共享种子做脚本回归／AI采样，再真人试玩。采样只为发现不可打或明显过强，不宣称AI胜率等于真人难度。若过强，优先下调生命32→28或降低回流频率；若过弱，先看AI是否会正确运用现有手值，而非增加隐藏免控。所有调参更新本表后再接入。
