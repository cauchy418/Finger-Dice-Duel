# 第一章：边境哨站·八战 — 剑士两段攻击

## 目标与配置

玩家战士·剑士，攻+2/防−1，左2右4；白板教官11生命，左2右3，无盾。先以无盾目标把追加与主攻击两次伤害完整展示，盾牌逐段抵挡已由六战教授。

## 操作与结算

己左2＋教官左2＝4，此时双4；必须点击“发动追加”。先追加固定4伤，无视双方攻防，命中附流血2回合；随后主攻击4＋攻2−目标防(−1)＝7伤，合计11击杀。追加先结算，流血已使目标防御−1，因此不能写成4＋6。

战报分别保留追加与主攻击，结算卡说明只有运算后双手相同且为4/6/8才能追加，追加可选、数字视为0，单盾只挡其中一次；本课白名单要求发动以确保展示完成。
