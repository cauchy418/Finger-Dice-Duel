# 第二章：法师高塔·七战 — 未发生的行动

2026-10-26，**设计待实现**，全局编号17。玩家法师·预言学派，20生命、攻0／防−1、距离∞；护卫20生命、攻防0／0，无盾、状态与元素。重点不是猜出下一次伤害，而是记录另一只手的快照。

典籍：“预言记住的是你没有改变的那只手。看清它，再看对方手里有没有相同的数字。”

## A：另一手快照与整次行动无效

玩家左3右4，护卫左1右4，玩家先行。

| 拍 | 操作 | 结果 |
|---|---|---|
| 1 | 己左3+护卫右4=7 | 开窗口，记录另一只手4；7本身不攻击，不额外选状态 |
| 2 | 护卫左1+己左7，本可算8 | 护卫另一只手为4，符合快照；整次正常行动无效，源手仍1，玩家无伤，不能先改成8再取消 |
| 3 | 玩家下个回合开始 | 窗口结束，明确显示结束记录 |
| 4 | 己左7+护卫左1=8 | 普通攻击8，护卫20→12；本次没有重新算7，不开新窗口 |
| 5 | 护卫右4+己右4=8 | 仍有4但窗口已关，实际造成9伤，玩家20→11 |

典籍：“被你记住的是对方的任意一只手，不只是它拿来运算的手。窗口一关，数字相同也不再生效。”

## B：不匹配的行动照常

重新建局，玩家3/2，护卫4/1。己左3+护卫左4=7，快照是2；护卫手里4/1不含2。护卫左4+己右2=6，正常落地7伤，玩家20→13。不能因护卫借了玩家的2就错误触发预言。

## 结束与验收

A、B完成后“试炼完成”，不要求击败护卫。结语：“你能让一次行动失去意义，却不能让时间停在那一刻。”

验收：快照来自另一手且不会随以后变化偷偷更新；检查行动者任一手；无效前不改手、不攻击／回复／合盾、不触发本次行动技能；正常回合流转继续，下个自身回合清窗口；不匹配照常。跳过、额外行动与回合开始免费攻击不冒充本段正常运算，写入复习卡，不混入强制演算。
