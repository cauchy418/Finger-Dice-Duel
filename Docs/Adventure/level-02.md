# 第一章：边境哨站·次战 — 勇士技能指导

> 设计先完成于2026-10-24，随后按此实现。对应初战名称统一为「第一章：边境哨站·初战」。关卡文件与存档内部编号Level1/Level2保留，避免名称变化丢失初战通关记录。

## 教学目标

沿用初战的老兵旁白、合法点击白名单、步骤高亮、固定对手脚本和半自由练习，集中讲解勇士「精通重击」。

1. **判定时点**：运算完成后、发起攻击时，自己的左右手点数直接相加为10。
2. **区分两种和**：运算的两个加数来自自己和对手；技能判定用自己的两只手，不能混为一谈。
3. **伤害顺序**：基础伤害×1.5，再加攻击、减防御；勇士攻+1/防0，常规重击4/6/8分别造成7/10/13点（目标防0时）。
4. **自动技能**：不增设发动按钮；在既有技能提示与战斗记录中确认实际触发。双手和10但没有发起攻击时，不触发。
5. **防御规则保留**：重击不自带穿盾或必中，不改变原有护盾、闪避和取消规则。本关不引入新的伤害机制。

## 剧情与关卡数据

初战结束，哨站老兵让勇士参加第二场校验：“会算数字只是开始，勇士要把两只手配成一记重击。”对手为哨站教官（白板，非新增可选角色），采用现有旧士兵头盔徽记；按后续要求新增全章共用的边境哨站庭院战斗背景。

| 项 | 设定 |
|---|---|
| 玩家 | 战士·勇士，生命20，攻+1/防0，距离1 |
| 对手 | 哨站教官，生命18，攻0/防0，距离1；关卡数据，不改白板或竞技数值 |
| 初始手值 | 玩家左1/右6；教官左5/右8；固定起手，不掷骰 |
| 初始状态 | 教官初始5沿用既有起手碎盾口径，不是完整盾；其他手为普通手 |
| 时长 | 推荐路线5个行动步骤，约2分钟；自由练习可延长 |
| 引导员 | 老兵，复用Adventure/guide_soldier |
| 失败保护 | 教官引导动作全是无效果运算；自由阶段也不进攻、回复或合盾，无安全运算则休整，沿用初战已确认策略 |

## 演算与教学步骤

| 步骤 | 行动 | 手值与伤害 | 生命变化 | 教学重点 |
|---|---|---|---|---|
| 1 普通攻击对照 | 玩家左1＋教官左5＝6，确认攻击教官 | 玩家变6/6，双手和12；普通基础6＋攻1＝7 | 教官18→11 | 不是攻击数字就自动重击；双手和12不满足条件；初始5不是盾 |
| 2 教官演算 | 教官左5＋玩家左6＝11→1 | 教官变1/8，无效果 | 不变 | 给下一步留下8作为加数，不改教学以外规则 |
| 3 精通重击 | 玩家左6＋教官右8＝14→4，确认攻击教官 | 玩家变4/6，双手和10；基础4×1.5＝6，再＋攻1＝7 | 教官11→4 | 运算和14与自身双手和10不同；更小的4也能靠重击打出7伤；技能自动触发一次 |
| 4 教官演算 | 教官右8＋玩家左4＝12→2 | 教官变1/2，无效果 | 不变 | 进入可安全探索的残局 |
| 5 半自由练习 | 放开全部合法点击，动态建议玩家右6＋教官右2＝8后攻击 | 玩家变4/8，双手和12；普通8＋1＝9，足以击杀 | 教官4→0 | 再次提醒并非每次攻击都有重击；也可自行改变手值、练习凑10 |

普通6与重击4的实际伤害同为7，既展示技能收益，也避免把“数字越大”误当作技能条件。自由阶段不要求再次发动技能才能通关；引导第3步已经确保完成一次真实重击。反复不进攻时按正常50轮上限判生命，玩家20高于教官至多18，不会因自由探索失败。

- 次战首次进入强制完成前4步；点错不推进，教官脚本不受人类点击白名单阻挡。旁白明确当前该点的手、双手和、普通/重击算式。
