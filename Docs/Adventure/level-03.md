# 第一章：边境哨站·三战 — 破阵者盾牌技能

> 2026-10-24设计，先落本文及四战、五战设计，再编写。玩家切换战士·破阵者，重点理解盾牌破碎的时机与流血来源，不修改技能规则。

## 目标与数据

玩家20生命、攻+1/防0/距1，左2右1；训练教官白板18生命、攻防0，左3右5，右5为关卡预先合好的完整盾。明确这是教官提前合成的盾，不把初始分配5教成完整盾。

## 七步剧本

| 步 | 操作与变化 | 教学点 |
|---|---|---|
| 1 合盾 | 己左2＋教官左3＝5，己左成盾 | 为技能准备完整盾 |
| 2 受击连锁 | 教官左3＋己右1＝4；己左盾挡，盾碎；玩家选择连锁打碎教官右盾 | 破阵者自己的盾碎，可连带打碎场上一面完整盾；本次被动破盾不附流血。引导只能选择教官盾，禁止放弃而卡死 |
| 3 双盾修复 | 己右1＋教官左4＝5 | 合成右盾，同时把另一只手的碎盾5修复为完整盾 |
| 4 教官演算 | 教官右5＋己左5＝10→1 | 无效果，为下一步留下1 |
| 5 主动用盾攻击 | 己左完整盾5＋教官右1＝6；本次保留另一面盾，不发动额外射程或连锁自己的盾；确认攻击，造成7伤，教官18→11 | 主动使用完整盾作运算源会先碎盾；本次攻击命中附2回合流血。点击现有“保留盾牌／不发动”选项，不由系统替玩家作答；按既有1v1流程继续攻击，不额外制造选择 |
| 6 流血观察 | 教官回合开始流血失去1点体力，11→10；左4＋己左6＝10→1 | 流血攻防−1，自己回合开始失去1体力；被动破盾与主动碎盾攻击区别 |
| 7 安全自由练习 | 开放合法操作，鼓励再次合盾/修复或进攻直至获胜 | 教官采用前两战的安全策略，不进攻、回复或合盾，无安全运算则休整 |

第5步已演示“盾作运算源”的主动碎盾流血；另一种“碎掉另一只完整盾换本次距离∞”放在四战。命中按现有口径：盾挡/零伤仍附流血，闪避/取消不附。流血持续目标自己的2个完整回合，重复刷新。

通关后可自由练习；自由练习保持该关初始手值和教官预先合成的盾，安全教官可能保留该盾，不再新增盾，旁白应按实际手值/盾状态建议操作。无误导地强调“安全阶段不新增盾”，不用“教官没有盾”。
