# 第一章：边境哨站·五战 — 经典先攻与自由对战

> 2026-10-24设计。按用户补充，明确接入先攻介绍；首次流程包含开场讲解→真实1d20投骰→合法分配→先攻开战，不跳过投骰。

## 目标与对局

玩家战士·破阵者，对手白板训练教官；均20生命，原角色攻防/射程。双方各投真实随机1d20，完全复用经典1v1的MatchStartController、骰子动画、分配选项和AI拆分策略，不使用固定骰点或教程安全AI。AI正常攻击、防御、回复、合盾，玩家可败，50轮按生命判胜/平局。重试重新掷骰与分配。

## 先攻说明（投骰界面持续显示）

- **小点先分配，大点先行动**：先分配者先公开手值，后分配者可看到并应对；分配先后不等于行动先后。
- **同点**：按现有同时分配规则，不泄露对方未公开的选择；行动先手依现有1v1规则为玩家。
- **2～18**：两手各1～9，总和等于骰点；**1大失败**：由对手任意指定自己的两手；**19小成功**：至少一手9；**20大成功**：自己自由指定两手。
- 分配只是起手：5不是完整盾、9不立即回复，战斗后仍通过运算触发效果。

## 交互流程

1. 从章内“五战”进入开场介绍，主按钮“学习先攻”进入投骰，次按钮返回章内列表。
2. 掷骰页标题标明“边境哨站·五战 · 经典先攻”。左侧直接显示老兵头像和动态旁白：投骰前解释分配与行动顺序，骰点落定后说明谁先攻，分配时指出由谁选择（含大失败代选）；同时持续显示小点先分配/大点先行动/同点先手简短提示；骰点、分配人、已公开手值与先行动者均由现有控制器提供。AI负责自己的选择及玩家大失败时的代分配，人类选择不被教程白名单锁定。
3. 分配完成后设置真实先手，才调用BeginTurn；不能先开始一回合再重设。若教官骰点较高，开战后首先由教官行动，旁白提醒当前先攻者。
4. 战斗全自由，左侧仅给经典与破阵者技能简短提醒，不建议“教官不攻击”、不限制选择。真实技能提示、战报和状态正常显示。
5. 胜利记录五战通关并给要点；失败显示“训练失利”，平局显示“训练平局”，均可“重新投骰”或返回章节，不记新通关。此前已经通关的标记不因失败删除。第五战不提供跳过先攻；投骰页也有返回章内列表按钮，不留退出死路。

先攻讲解独立于前四战安全教学，普通经典页面不显示章节专属标题/提示/返回按钮，退出后不能把关卡设置带入竞技。全章共用哨站背景。
