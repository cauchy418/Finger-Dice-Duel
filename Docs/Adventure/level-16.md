# 第二章：法师高塔·六战 — 借来的生机

2026-10-26，**已实现**，全局编号16。玩家法师·死灵学派，20生命、攻0／防−1、距离∞。三份必修样本分别隔离抵挡／免费攻击、死亡交换与力场反例。

典籍：“你留下的一个小数字，可能替你挡下一刀，也可能在下一回合唤回一缕余烬。”

## A：2抵挡，1免费暗蚀

玩家开场**14/20生命、左2右3**；护卫20生命、左3右8、攻防0／0，无盾，无暗蚀免疫，护卫先行。伤势为开场公开配置。

| 拍 | 操作／选择 | 预期 |
|---|---|---|
| 1 | 护卫左3+己右3=6，攻击玩家 | 直接点击己左2发动抵挡；左2→1，伤害0，玩家仍14 |
| 2 | 玩家回合开始，有可用1 | 自动弹**角色目标**，不先选发动手、不列“目标·手”；选护卫 |
| 3 | 免费1点暗蚀落地 | 护卫20→19，附腐朽2回合；自己的1不消耗，正常行动仍可用 |
| 4 | 己右3+护卫左6=9 | 正常回复9，实际回6，玩家14→20，证明免费攻击没有替代正常行动 |
| 5 | 护卫右8+己左1=9 | 腐朽阻止回复，护卫仍19，不能误算回至20 |

复习入口重放时可在免费攻击阶段点“放弃攻击”，应直接进入正常行动，不消耗1、不结束本回合。

## B：死亡后换0～2对手值

使用4人公开2v2：1位玩家（1/3、20生命），2位**受损奥法护卫**（6/8、1生命），3位另一奥法护卫（8/2、20生命），4位协作护卫（1/1、20生命）。1／4为甲队、2／3为乙队；其余角色休整，不随机攻击。玩家先行。

1. 回合开始免费暗蚀选择2位，1点使其真正死亡；3位仍存活，对局未结束，必须允许死亡交换弹出。
2. 直接点己右3，再直接点死者右8，交换为己1/8、死者6/3；不触发8攻击、不合盾、不回血。
3. 再次询问时点“结束选择”，验证只换一对也合法。可选复习再交换己左1与死者左6，得到6/8，说明这样会失去持1的下一次免费暗蚀资格。
4. 本回合正常行动仍可用：己右8+3位左8=16→6，攻击存活敌人。免费击杀、交换、正常行动分别记录，不提前“再来一局”。

样本目录另可演示第一问直接结束（0对），以及确实交换2对；每只手最多参与一次，不能重复点同一只手刷交换。

## C：力场不能被2抵挡

玩家2/3、20生命，护卫3/2、20生命，攻防0／0、攻击类型力场，护卫先行左3+己右3=6。力场造成7伤，玩家20→13；手值2保留，不能记作抵挡成功。

此段不要求点2，明确提示不可抵挡。现行 `TryBlockAttack` 已拒绝力场，但收集端仍可能排入2候选；实装前核对并修正错误的可发动提示，不改力场与2抵挡规则。

## 完成与验收

完成A、B的一对交换／正常行动及C后“试炼完成”，0／2对为可选复习。结语：“死者留给你的不是一张更大的牌，而是一次重新安排手牌的机会。”

验收：真实2→1、免费暗蚀固定1且无视攻防、腐朽封回复、放弃不耗正常行动、非末敌死亡不提前胜负、尸体手仍可点且无遮罩、每手最多一次、交换不触发效果、力场不消耗2。最后一名敌人已死亡且游戏结束时不排无意义换手。
