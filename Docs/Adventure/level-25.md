# 第三章：残旗战场·五战 — 古贤的庇护

2026-10-30，**已实现**，全局编号25。公开2v2固定玩家1／同袍4、对手2／3，玩家为古贤之誓，攻−1／防+1／距1。三个独立样本。[共同要求](chapter-03.md)。

## 一：破盾束缚，仍有一手可用

玩家20生命、完整左5盾／右2；同袍2／2，教官甲1／1，教官乙2／3，均20生命。玩家先动：左5借同袍左2=7，盾碎触发“自然之怒”，发动并选择邻近教官甲，附束缚2回合。7无攻击，破盾本身没有生命伤害，不触发不灭哨卫。

教官甲下一自身回合由真实随机决定一只不能行动的手，展示锁定与另一只可动。用当前合法手借同袍右2，只会得到3或5，不攻击；回合末束缚2→1。其他NPC休整；玩家左7借教官乙左2=9，按普通规则回复，无新破盾。教官甲再动一次，仍只能选合法手，结果分支仍为3或5，回合末1→0。

固定随机种子保证可复现，但指引读取真实锁定手，不把两手都禁用，也不伪造两回合“无法行动”。这是玩家回合中独立破盾技能附状态，基础2回合不因攻击格挡扣时长。

## 二：受伤后仍至少10，先顾同袍

重建玩家13生命、1／2、无盾；同袍10生命、左1；教官甲左3借同袍左1=4攻击玩家。4−防1=3，玩家13→10，仍存活且至少10，触发“不灭哨卫”。选择范围内同袍，10→12；玩家保持10。

这一步人物选择保留范围内全部正常候选，仅同袍可点；不是所有队友同时回复，也不是玩家可以任意跨距离治疗。

## 三：受伤后低于10，转为自愈

重建玩家12生命，同袍10，其余沿用第二段。相同攻击造成3，玩家12→9，再自愈2成为11，同袍保持10。阈值只检查本次受伤后、回复前的9，不能因为回到11又补触发一次同袍治疗。0伤盾挡不触发此回复。
