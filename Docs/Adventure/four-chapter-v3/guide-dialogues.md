## 1：伤者拦路（8句）

1. 你是一名重甲战士，攻击加二、防御加二，没有特殊技能。
2. 借老兵的三算出四，再选择老兵攻击。
3. 四点基础伤害加上攻击二，这一击造成六。
4. 老兵以四反击，减去你的防御二，只造成二。
5. 借他的四算出五，举起完整护盾。
6. 护盾挡下一次攻击后会破碎。
7. 用碎盾算出九回复，超过生命上限的部分不保留。
8. 相加满十记作一，再看老兵的运算。

## 2：精通重击与物理易伤（7句）

1. 用左手二借教官左二算四。普通一击造成五点伤害。
2. 看教官运算，留意他右手的三。
3. 用右手一借三算四。精通重击使基础四乘一点五，再加攻击一，造成七点伤害。
4. 重击附带两回合物理易伤。挥砍、钝击和穿刺命中时，攻防结算后的伤害乘一点五，向上取整。
5. 用左手四借四算八。易伤把九点伤害增至十四，命中后图标仍在。
6. 教官经过第二个自身回合，物理易伤到期。
7. 用右手四再算一次八，观察这一击恢复为九点伤害。

## 3：破阵强袭（5句）

1. 盾碎时发动破阵强袭，选教官的完整盾。
2. 再次合盾，还能修复另一只手的碎盾。
3. 使用完整盾运算打出攻击，会给命中的目标留下流血。
4. 看教官回合开始失去体力，并观察他的攻防变化。
5. 教官还会架盾，交手时留意他的徽记与冷却。

## 4：跨过距离（5句）

1. 石头占着座位，双方距离为二。
2. 这次攻击够不到，选择放弃攻击。
3. 先合成完整盾，再用另一只手算出八。
4. 发动无畏冲锋，碎掉完整盾，让本次攻击距离变为无限。
5. 还可用一次行动推开路障，缩短之后的距离。

## 5：经典先攻（3句）

1. 双方各投一枚二十面骰，小点先分手值，大点先行动。
2. 一点由对手替你分配，十九至少一只九，二十可自由分配。
3. 按骰点选好双手，再与教官交锋。

## 6：奥术射击（4句）

1. 教官会架盾，先用八的穿透箭越过完整盾。
2. 算出六，强力射击让基础伤害再加二。
3. 等他重新合盾，再用四发动魔能齐射。
4. 第一段破盾，第二段继续命中，留意两段各自结算。

## 7：卓越战技（7句）

1. 教官射程为二，观察招式怎样改变他的攻势。
2. 选择流血，看回合开始扣血与攻防下降。
3. 选择跛脚，他的射程便会减半。
4. 选择震慑，他仍能运算却不能攻击。
5. 选择倒伏，再用下一击观察增伤。
6. 最后选择不附加招式，比较这一击的结果。
7. 教官也会架盾，别忽略徽记里的冷却。

## 8：双刃连斩（3句）

1. 把双手配成双四，再发动双刃连斩。
2. 追加一段先结算，命中附流血，再看主攻击。
3. 两段攻击分别处理防守，接下来自己寻找连斩机会。

## 9：战术眼光（7句）

1. 战术家的攻防都是零。选定两只手后，战术眼光让你选择加法或减法。先用一加三算四。
2. 看教官完成运算，留意他右手的六。
3. 用右手四借六，选择减法。负二记作八，可以攻击。
4. 教官会调整左手。减法始终用你自己的数字减去借来的数字。
5. 用左手四借四，选择减法。差为零时记作一。
6. 留意教官刚调出的二。负数按十回绕，例如负一记作九。
7. 用左手一借二，选择减法算出九，回复体力。

## 10：哨站骑士（3句）

1. 骑士会架盾，半血后还能用一次整军回复六。
2. 从战士子职中选择自己熟悉的一位。
3. 完成经典先攻，抓住他的护盾与整军空隙。

## 11：雷声（6句）

1. 精魂能调整自己的手值，留意它准备的加数。
2. 选择雷鸣永久抗性，再算四引出雷声。
3. 雷鸣留下残响，使目标只能攻击距离一内的角色。
4. 风暴导向可额外纯运算一次，先选自己的手，再点击加数。
5. 看精魂够不到你，运算后的八仍会保留。
6. 风暴之护决定抗性，暴风狂怒的攻击属性则另行判定。

## 12：雷光（5句）

1. 这次选择闪电永久抗性，再引出一道闪电。
2. 感电会在目标回合开始伤及自身和相邻角色。
3. 一被减半仍向上取整为一，抗性不等于免伤。
4. 这次放弃风暴导向，观察精魂下一回合的感电。
5. 精魂会在交锋中使用闪电，留意你的永久抗性。

## 13：不燃之壳（5句）

1. 选择火焰龙族先祖，获得永久火抗；攻击有八成概率改为火焰。
2. 龙族火焰穿透精魂的免疫造成伤害，免疫仍阻止燃烧。
3. 再打一击，看免疫消耗后火焰留下的燃烧。
4. 趁燃烧还在时再命中，可将剩余时长延长一回合。
5. 观察精魂回合结束扣血，再用九回复。

## 14：霜痕（4句）

1. 选择寒冷龙族先祖，先触碰精魂的一次寒冷免疫。
2. 免疫消耗后再次命中，让它覆霜两回合。
3. 看原本的八减为四，覆霜仍允许它行动。
4. 留意身上的寒冷永久抗性，再用九回复。

## 15：翠毒（4句）

1. 选择毒素龙族先祖，先观察精魂的一次毒素免疫。
2. 被免疫的毒击不会留下中毒。
3. 再次命中以后，观察中毒在精魂回合开始扣二。
4. 再次附加中毒可延长它的时长。用九调整体力。

## 16：蚀酸（5句）

1. 选择强酸龙族先祖，先消耗精魂的一次强酸免疫。
2. 看精魂反击，保留自己的攻击机会。
3. 再次命中，让强酸降低它的防御。
4. 观察精魂行动后强酸图标和防御数值的变化。
5. 借精魂的手算九，回复体力。

## 17：命火（7句）

1. 精魂有一次安魂，使你回复八点体力。
2. 坟冢之力会在首次体力归零时，将你托回一。
3. 双手和十时选择黑暗术，暗幕将笼罩近旁角色。
4. 看精魂的攻势减弱，再攻击失明的它。
5. 幽暗之瞳让本击伤害加二，并改成暗蚀。
6. 腐朽使它算九也无法回复，再用自己的九稳住气息。
7. 回廊重赋会返还刚才消耗的坟冢之力，留给接下来的交锋。

## 18：万象相生（10句）

1. 回响能映照术式、刻印自身状态，并在观察后有限整备。
2. 狂野魔法每段各自判定属性，先跟随此处映出的流光。
3. 雷鸣叠残响会化为眩晕，观察一次受限运算。
4. 闪电与残响或雷鸣与感电相遇，会刷新旧状态并引发耳鸣。
5. 寒冷遇覆霜或潮湿会冻结，等它经过不能行动的回合。
6. 寒冷打冻结会增伤并保留冻结，打燃烧则增伤并清除燃烧。
7. 火焰清覆霜或潮湿时不留燃烧，清油腻时却照常留下燃烧。
8. 闪电打潮湿会增伤，保留潮湿并附感电。
9. 强酸与中毒互相配合，会附新状态并将旧状态刷新至二。
10. 观察实际图标与伤害，余下的反应可在秘法手册复习。

## 19：三相（7句）

1. 回响能换装和架盾，留意它当前的武装。
2. 算出攻击数字后可放弃本击，先存光耀。
3. 待用类型还未消耗时，你拥有该类型的抗性。
4. 下一次攻击释放光耀，观察目盲图标和可借用的手。
5. 再存力场，穿过它的盾与正防御，力场不留下元素负面。
6. 最后存心灵，观察此次恐慌或震慑带来的行动限制。
7. 不想改属性时可以选择不发动，照常攻击。

## 20：万象回响（4句）

1. 万象回响每隔一次普通攻击会轮换元素术式。
2. 每三个自身回合，它还会按顺序获得一种一次免疫。
3. 留意免疫图标，试探之后再追击。
4. 选任意术士子职，完成经典先攻再与它交锋。

## 21：剑上术式（5句）

1. 护卫会改变武装，留意它此刻的伤害类型。
2. 用完整盾算六，先选火焰，再确认攻击目标。
3. 这次碎盾附魔会直接用于眼前这一击。
4. 受到光耀实际伤害后，选择记录这一类型。
5. 再次打出攻击数字，释放刚才记录的光耀。

## 22：王车易位（6句）

1. 这两名护卫与同袍各有座位，力场仍能越过完整盾与正防。
2. 连续用四和六，使自己的手值变成四与六。
3. 双手无序匹配同袍时，可以用王车易位换位并跳过本回合。
4. 先查看或取消预览，再选择同袍发动。
5. 距离立刻变化，本轮仍按原顺序行动。
6. 等到下一轮，观察新的座位顺序。

## 23：奥术守御（7句）

1. 护卫会架盾和切换武装，先看它的普通攻击。
2. 算二选择自己，再选择物理整组法术抗性。
3. 受击后抗性仍在，算四放弃攻击存为奥术守御。
4. 下一击先被抗性减半，再由守御吸收，屏障整份消耗。
5. 再次算二改为火焰抗性，旧物理抗性随之撤销。
6. 分别观察普通攻击和火焰攻击的伤害。
7. 最后用九回复，法术抗性会留到施术者死亡或重新施放。

## 24：惑控（5句）

1. 先观察护卫攻击；实际受伤后，可对伤害来源附加失能。
2. 先算三，等护卫再次进攻。失能使他的攻击伤害归零。
3. 惑控效果会在目标之后实际掉血时解除。
4. 用八实际伤到护卫后，可对他附加魅惑。
5. 观察魅惑的一次随机行动，再用攻击解除它。

## 25：死灵（7句）

1. 主护卫偶尔使用力场，另一名侍从已经濒死。
2. 把自己的二变成一，抵挡这一段普通攻击。
3. 持一时免费暗蚀自动提出，只需选择侍从或放弃攻击。
4. 击杀以后，用自己的右手与死者右手交换，再选择结束。
5. 免费攻击没有花掉正常行动，继续算九回复。
6. 再次准备二，看它无法抵挡力场。
7. 主护卫会在后续交锋中每第三次普通攻击改用力场。

## 26：预兆（6句）

1. 护卫会调律和架盾，观察它计算完成后的结果。
2. 打出七，先记录另一只手的四。
3. 持七时消耗预兆四，改写护卫刚算出的攻击结果。
4. 再通过运算记录五，将下一次攻击改成完整盾。
5. 准备并记录九，这次先选不发动保留它。
6. 最后用预兆九改写自己的结果，让它成为回复。

## 27：幻术（5句）

1. 手上有二时，先看对手准备用哪只手触碰你的哪只手。
2. 发动幻术默发，改用自己的另一只合法手作为加数。
3. 下一次保留原加数，比较两种结果。
4. 受攻击时双手差二，可以把较小手变成二减半伤害。
5. 这次选择幻影实体，再观察伤害。

## 28：变化（6句）

1. 双手数字无序相同时，可以在回合末对目标施放变形术。
2. 把自己的手配成四与六，选择护卫变羊。
3. 羊有独立八点生命，攻防负二、距离一，原技能暂停。
4. 观察两次自身回合后恢复原形。
5. 再次把双手配成一与七，选择护卫变羊。
6. 用八打出十，羊承受八，原形承受溢出的二。

## 29：剑歌（7句）

1. 护卫会架盾，先以十四生命、四与六的双手迎战。
2. 借四算八，使双手和十四等于体力，在回合末选火焰进入剑歌。
3. 剑歌使攻防各加一，攻击改为所选类型。
4. 借一算九，实际回复体力以后剑歌仍保留。
5. 再借二算八，发起攻击也能维持剑歌。
6. 满血时再次算九没有实际回复，回合末剑歌会结束。
7. 合成完整盾也可维持剑歌，接下来自己寻找机会。

## 30：法师幻影（3句）

1. 幻影拥有永久火焰、寒冷抗性和毒素免疫。
2. 每三次普通攻击实际伤人，它会回复三点生命。
3. 选择法师子职完成先攻，用合适的术式突破它。

## 31：借数与目标（5句）

1. 借同袍的五算六，再选邻近护卫为攻击目标。
2. 被借数的同袍不会因此受伤或失去原手值。
3. 再借远处对手的二算四，仍可选择邻近者攻击。
4. 借谁的手与攻击谁，是两次独立选择。
5. 同袍会用有限急救援助附近队友。

## 32：王冠成长（4句）

1. 护卫会架盾，同袍也能提供加数。
2. 先攻击邻近者，再借同袍的一算五举盾。
3. 盾碎以后，王冠之誓的攻击距离永久增加。
4. 攻击加成随距离变化，再用八攻击原先够不到的对手。

## 33：卫护斩（4句）

1. 借同袍的三算四，这会合盾并触发卫护斩。
2. 卫护斩选择角色目标，不选择目标的手。
3. 用完整四盾算五，旧盾破与新盾成各触发一次卫护斩。
4. 再用完整五盾算六，碎盾冲击后正常发起攻击。

## 34：守护之誓（5句）

1. 同袍也是奉献之誓，会合盾、代挡与卫护斩。
2. 没有完整盾时，你不能发动守护之誓。
3. 先为自己备盾，再选择为邻近同袍代挡。
4. 代挡打碎自己的盾以后，仍会触发卫护斩。
5. 同袍AI也会用自己的完整盾保护你，观察这次代挡。

## 35：古贤（6句）

1. 破盾时发动自然之怒，选择对手附束缚。
2. 束缚随机锁住一只手，另一只手仍能行动。
3. 等他经过自身回合，观察束缚自然到期。
4. 受伤后体力仍不低于十时，不灭哨卫可以治疗别人。
5. 降到十以下时，改为治疗自己。
6. 留意同袍体力，再决定把治疗给谁。

## 36：憎恨灵光（5句）

1. 两名护卫都能架盾，观察他们形成的完整盾。
2. 算出五时，破誓者会发起攻击而不是合盾。
3. 保留另一只五，等待对手向你进攻。
4. 发动憎恨灵光，把整次攻击转向另一名护卫。
5. 这不是替同袍代挡，目标由你重新指定。

## 37：征服威压（6句）

1. 手上有五时发起攻击，攻击结束以后攻击加成才增长。
2. 第一次攻击比较的是增长前的数值。
3. 受攻击时仍持五，结算以后防御也会增长。
4. 以更高攻击出手，或以更高防御受攻击，会令目标恐慌。
5. 没攻击的回合会衰减攻击，回合末无五则衰减防御。
6. 这份技能成长最低降到零，不会额外变成负数。

## 38：仇敌誓言（7句）

1. 先把甲标为仇敌，对他伤害加一，对其他人减一。
2. 算五备盾，乙来袭时选择把标记转给乙。
3. 仇敌打碎你的盾，会触发复仇之魂。
4. 用碎盾做一次纯运算，只改手值，不额外攻击。
5. 甲再次攻击时可以改标回甲。
6. 仇敌死亡后选择新的存活目标，再继续追击。
7. 同袍会提供加数和攻击，攻击目标仍由各自决定。

## 39：八人协作（8句）

1. 这里是公开阵营战，你有两名同袍和五名对手。
2. 借远处同袍的手合盾，用卫护斩打邻近前锋。
3. 对手攻击邻近同袍时，用完整盾代挡。
4. 距离三的那次来袭不能由你援护，即使手上仍有盾。
5. 用普通八击杀前锋，观察击杀奖励。
6. 此时敌方该阵营尚余两人，因此得到两次额外行动。
7. 先算九回复，再完成一次运算，随后按轮序继续。
8. 普通同袍有有限急救，弩手的六会额外增加一点基础伤害。

## 40：共举残旗（4句）

1. 指挥官半血后可用一次集结令，治疗自己与近旁队友各四。
2. 弩手普通六的基础伤害加一，同袍古贤之誓会帮助你。
3. 选择圣武士子职，按四人经典先攻分手并落座。
4. 照应同袍，击败敌方两人。
