# 元素精魂、元素回响与新美术

## NPC定义

本章NPC不作为可玩子职，不加入竞技角色池。不同元素精魂共用一个徽记，用伤害图标与名称识别武装，不为十种属性复制十个角色。

| 稳定ID | 名称／徽记 | 作用 |
|---|---|---|
| gallery_spirit | 元素精魂 | 回廊1～7，按课表换名及武装 |
| gallery_echo | 元素回响 | 回廊8～9，承载反应刻印与三相换装 |
| gallery_echo_archon | 万象回响，复用回响徽记 | 终战44生命强敌，公开两项能力 |

教学与实战能力分开列在徽记中，当前不可用的教学能力不在实战按钮中继续触发。角色目标按钮、战报头像、伤害／援护动画都由稳定ID映射同一枚资源，不能按“火焰精魂”等显示名查图。

## 教学能力与次数

| 能力 | 行为 | 限制 |
|---|---|---|
| 演练调律 | 自身真实回合开始调整自身可用、无完整盾的手值，为下一次运算提供加数 | 不改玩家手；冻结、变形或眩晕技能暂停时不越权 |
| 元素壳膜 | 对龙族四课，开场一次对应类型免疫 | 一次攻击落地按公共临时亲和规则消耗；实战不重新附加 |
| 裂纹铭刻 | 强酸课给自己一次强酸易伤 | 限一次，只在已观察强酸后施加 |
| 安魂 | 幽影课精魂回合开始正常为玩家回复8 | 限一次，遵守治疗限制，在首次保命后、失明减伤示范前使用 |
| 回廊重赋 | 幽影课进入实战前返还教学消耗的一次坟冢之力 | 限一次，明确提示；不重置普通对战角色技能，不在重试上叠加 |
| 映照 | 狂野课控制当前教学正式攻击段的属性 | 只覆盖教学、仅正式攻击推进；试炼与退出时恢复原概率 |
| 刻印 | 狂野课清已观察的上一例负面，再给自己本例前置状态 | 每例一次，共13；先实际观察冻结／眩晕等自然过程，不能抢先解控 |
| 训练整备 | 狂野课组间净化已观察负面并回复16 | 每组至多一次，整课7次；不清玩家资源或制造生命上限 |
| 三相换装／架盾 | 塑能课换光耀武装，或在规定节点形成完整5盾并增加正防 | 行动成本和节点预告；实战只保留课表固定配置 |

黑暗术失明、目盲、腐朽等定义继续由手册统一提供，不在新角色图鉴里重复解释。需要观察的负面必须在真实核心伤害／回合计时中触发，不能为了画面先播图标再直接删除。

## 终战能力

万象回响的轮转术式与折光外壳严格按章节表；徽记悬停显示当前轮转位置、下一次免疫类型及其触发回合。临时免疫不会重复补到永久，不能为了克制玩家的龙族元素即时改序。

普通课与终战的能力介绍合计仍受10句教学限制，完整定义、剩余次数与冷却放徽记。终战叙事可短，不增加多段强制操作。

## 实现验收清单

- 四章共40关ID唯一，全部教学句数≤10，剧情与教学分离。
- 雷鸣和闪电演示必定打出对应类型，狂野课13次命中覆盖全部11类反应；正式试炼及退出不残留固定随机覆盖。
- 龙族四课分别由玩家点击元素选择，并验证一次免疫不附状态、正常命中附3回合基础状态。
- 幽影课首次保命实际触发，不被护持替代；额外资源返还由NPC技能公开完成。
- 防护课不再出现易伤／免疫检查点；剑咏者实际回血保留、满血回复不保留。
- 教学结束中央提示只出现一次，敌方恢复公开最佳状态后正常AI；再次试炼恢复同一基准，不叠补给。
- 老存档11～30不误写到新回廊11～20；旧已解锁入口保留。
- 新背景与两枚徽记在人物、技能目标、图鉴式敌技说明和动画快照中均无缺图，检查720p／1080p布局。
