# 共同流程：指引、整备、实战与重试

**已实现共同流程**，适用四章；普通竞技规则不变。

## 教学结束的中央提示

教学目标全部完成后，先结束当前运算、攻击、状态计时、死亡选择、回合末技能及动画，再暂停推进，在屏幕中央弹出：

> **实战试炼**
>
> 接下来进入实战试炼，对手会恢复至最佳状态。
>
> 【进入实战】　【返回关卡】

这不是通关结果，不授予完成记录。点击进入实战后执行一次整备，从真实下一行动者继续；不能多跳或抢走一个回合。四、八人场同样在全部嵌套请求结束后进入。最后实际胜负仍先留场显示“试炼结束”，由玩家点击查看结果。

## “最佳状态”的可实现定义

每课需显式配置实战敌方名单与实战开局表，不用泛化Reset恢复整个游戏。

| 项目 | 切换时处理 |
|---|---|
| 实战敌方生命 | 解除变形，恢复原形生命上限并回满；不使用普通治疗，因此腐朽不拦这次整备 |
| 敌方负面、临时亲和 | 移除负面及教学用临时易伤／抗性／免疫，结束教学铭刻；玩家施加的临时负面也结束 |
| 敌方能力 | 恢复公开实战武装、固有亲和、次数与冷却；不暗加未介绍的技能或数值 |
| 敌方手值及盾 | 采用课表公开的实战起手；按配置形成完整盾；不根据玩家当前数字选最优手值 |
| 座位、距离、队伍 | 保持教学结束时的实际座位与队伍，王车易位不换回；路障是否已移动也保持 |
| 教学牺牲单位 | 死灵受损侍从、残旗被击杀前锋等不列入实战名单，死亡不撤销、不返还被交换的手值 |
| 玩家及同袍 | 保留手值、生命、技能成长、预兆、仇敌标记、形态、气等；存活者正常尝试回复6，受腐朽等限制，不复活 |
| 对敌方的持续技能标记 | 诅咒／仇敌等由玩家持有的技能资源不因敌方整备自动清空；若其目标已死亡仍按原死亡流程处理 |
| 教学限制 | 解除护持、强制按钮、NPC调律和固定随机类型，改正常AI与正式随机概率 |

幽影魔法课另有已预告的NPC能力“回廊重赋”：整备时仅一次返还教学中消耗的坟冢之力，再保存实战基准快照；其他课不默认刷新玩家一次性资源，重试不额外叠次数。

整备的敌方血条、状态、手值变化有一次清晰短表现；中央提示已预告恢复，不再追加开发解释。人物徽记悬停显示试炼武装、亲和及能力，不只写“特定对手”。敌方能力通过前面少量指引对话介绍，开场剧情不列技能表。

第五战先攻课、各章终战没有强制战斗演示：先攻分配完成时已处最佳开局，不再覆盖真实骰点手值；终战直接实战，不伪造“教学完成”。其失败入口仍按下节统一处理。

## 实战计时

普通课教学预算目标20轮以内，最长反应课目标25轮、上限30轮。实战另享完整50轮预算，显示“试炼1／50”；不是把教学耗时算成玩家少了二十多个实战回合。

实现建议：保留游戏绝对RoundCount及角色时间锚点，记录TrialStartRound，用本阶段轮数进行剧情胜负上限检查；不要把全局轮次改回0，使幽灵出手、状态、换位等绝对轮次失效。50轮到限仍按普通同模式生命／队伍规则判胜，不制造教学专属必胜。

## 失败结果与两个重试入口

失败或平局时提供下列主按钮，均不清旧通关记录：

- **重新指引**：回到该关开头，播放剧情与指导，按本课初始配置建立一次新尝试。
- **再次试炼**：直接恢复这次实战开始时的基准状态，不回放指导、不给第二份额外补给。
- **返回关卡**：回到本章关卡列表。

首次确认进入实战后保存完整TrialStartSnapshot：双方／多方角色、手与盾、生命、状态剩余回合及来源、永久／技能抗性、成长、技能次数、气、形态血池、预兆、标记、座位与队伍、路障、轮序和当前行动者。再次试炼从该快照创建新尝试，不能只创建NPC回满而保留玩家死亡，不能反复叠加回复6或永久成长。清空上次尝试的攻击／动画／待答队列；新战报分尝试记录。

随机种子每次新尝试正常产生，固定的只有公开基准状态；不把教学的ForcedRoll、心理分支或伤害免疫演示队列带入实战。风暴之护、龙族先祖等开场选择保留原先已选值；重新指引才重新选择。终战再次试炼保留本次选角与已完成的真实先攻结果；要重选角色可从结果页返回选角。

若在实战前退出，当前版本不承诺半局续存；重进可选择重新指引，已通关课也可按公开实战预设直接挑战。切勿把“退出后创建的公开预设”描述成恢复了未保存的教学进度。

## 指引与高亮

发动／不发动、放弃攻击等正常选项全部显示，只高亮和启用本步所需项；纯运算选择手时点击战场手牌，选择角色才列角色按钮。冻结或没有合法操作走公共跳过，不把观摩写成普通任意跳过。固定类型演示必须等真实命中、状态触发及计时完成才通过检查点，不仅检查点击按钮。

全部40关的台词表见guide-dialogues.md；一条提示可覆盖相邻的准备运算和其观察结果，准备步骤不再各开一条重复对话。提示翻页不撤销操作。敌技对话、战斗教学合计不超过10句，剧情对话另计。
