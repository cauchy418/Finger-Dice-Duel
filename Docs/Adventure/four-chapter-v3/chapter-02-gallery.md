# 第二章：万象回廊——十战设计

**已接入运行时**。本章使用新的万象回廊背景，讲述者为“回廊铭文”，使用元素回响徽记。每关一段剧情开场，随后少量技能／操作指引；角色徽记承载完整技能及NPC能力。统一切换、补给和重试见[共同流程](common-flow.md)。

## 课表与实战配置

玩家原职业数值、20生命上限不变，普通课NPC均为0／0。默认普通攻击近钝击远穿刺；元素武装仅在表中指定的实战阶段固定生效。每关实战重新起手的敌人左／右手为3／2、无完整盾，除第九与终战另行列明。教学牺牲单位没有新增，均为一对一；不提前展开正式队伍操作。

## 初战：回廊的雷声

风暴术法起手1／2，精魂3／2、26生命，双方距离2。先选择风暴之护的雷鸣永久抗性；其他抗性按钮仍显示但本步不可选。

1. 左1＋精魂左3＝4：暴风狂怒本击固定为雷鸣，实际命中并附残响2回合。
2. 风暴导向选择刚用的左4，加精魂右2变6；只改变手值，不攻击、不回复、不合盾、不推进状态。
3. 精魂右2＋玩家左6＝8：残响使其无法攻击距离2的玩家，走真实放弃攻击；运算结果仍为8。
4. 检查永久抗性仍在、纯运算没有攻击、精魂残响至少经过一次自身计时，再弹出实战提示。

暴风狂怒只在这次教学攻击使用ForcedRoll=40，不能把永久抗性选择当作决定攻击属性。实战恢复40%闪电／40%雷鸣／20%普通概率；石台距离仍为2，雷鸣精魂恢复课表配置，残响清除。

## 次战：雷光的余波

同一子职起手1／2、精魂3／2，距离1。风暴之护指定闪电抗性，首击固定闪电（ForcedRoll=0）。

1. 左1＋精魂左3＝4：闪电命中，目标感电2回合。
2. 风暴导向本次选择不发动，与初战的发动形成对照。
3. 精魂自己的真实回合开始，感电对自身及相邻玩家结算1点闪电伤害；玩家永久抗性对1点减半仍向上取整为1，不写“免伤”。
4. 观察一次波及和状态计时即可；不为刷完整两回合再增加重复对话。

实战关闭固定随机值；精魂固定闪电武装。此关不提前施加潮湿，导电增伤留给八战。

## 三～五战的共用演算骨架

龙族血脉玩家1／2、精魂3／2，精魂拥有一次对应类型免疫，无其他亲和。首次自身回合必须由玩家点击指定龙族先祖类型，永久抗性与固定攻击属性均显示在状态栏；余选项显示但禁用。

| 顺序 | 真实运算／事件 | 观察 |
|---|---|---|
| A | 玩家左1＋精魂左3＝4 | 免疫阻止本击伤害和对应负面，临时免疫按公共规则消耗 |
| B | 精魂在自身回合将左手调2，再用右2＋玩家左4＝6，普通钝击 | 教学武装保持物理，不给玩家附会改变运算的元素状态 |
| C | 玩家左4＋精魂左2＝6 | 本次正常元素命中，对应负面首次2回合 |
| D | 精魂自身回合观察负面，再用右6＋玩家右2运算 | 寒冷时原8被覆霜减为4；火焰／毒素按真实时点扣血 |
| E | 精魂本回合准备左7；玩家右2＋7＝9 | 正常回复，为实战留出体力，不后台改玩家数字 |

精魂教学攻击0加成，玩家防−1：B的普通6为7伤；D寒冷分支普通4为5伤，其他普通8为9伤。玩家起始20，至少保留4生命，之后9正常回复，再按共同规则补给6。不得为了相邻课复制同一原始元组而覆盖已改变的玩家手值。

### 三战：火焰与不燃之壳

指定火焰龙族先祖。A免疫时不附燃烧；C普通6造成6并附燃烧2回合；D回合结束燃烧真实扣3。说明已有同名状态时可以延长一回合，余下龙族课用图标计数提醒，不重复朗读整套技能。进入实战后精魂没有演示用免疫，固定火焰攻击。

### 四战：霜痕

指定寒冷。C附覆霜3，D的普通8真实改为4，不能写为不能行动；覆霜到期会附潮湿，只在徽记与手册补充，八战再实操冻结。首击寒冷免疫不留下覆霜。实战正常寒冷交锋，不延续教学的固定物理武装。

### 五战：翠毒

指定毒素。C附中毒2，D回合开始扣2；A免疫时没有中毒及其后续扣血。只强制观察一次真实扣血。实战的毒素武装使龙族永久毒抗有实际作用；伤害仍可能因取整而非0。

## 六战：酸蚀与弱点

指定强酸，沿用共用A～C。C附强酸3，目标防御−2。额外增加一次真实攻击，集中完成降防与易伤，不再让防护学派承担此教学。

- D之前精魂使用一次“裂纹铭刻”，给自己一次强酸易伤；本回合左手改8，右6＋玩家右2＝8普通物理攻击。
- 玩家左6＋精魂左8＝4：正经攻防后的应有伤害为4−(−2)=6，易伤×1.5为9；一次亲和消耗，已有强酸延长1回合。
- 精魂下一回合普通右8＋玩家左4＝2，不攻击，同时左手调7；玩家右2＋7＝9正常回复。

免疫、易伤均有实际状态图标，NPC徽记说明裂纹铭刻限一次；临时易伤不得被写成强酸本身的固有效果。进入实战不重新授予演示用易伤或免疫。

## 七战：幽影中的命火

幽影魔法起始5／20生命、双手1／6；精魂3／2、28生命，先手为精魂。正常基础攻击近钝远刺，教学全程不先给玩家腐朽。

1. 精魂右手预备3，用左3＋玩家左1＝4钝击，玩家防−1实际受5：原形归0，由坟冢之力恢复至1。
2. 玩家左1＋精魂右3＝4，双手4／6和10，回合末选择黑暗术；精魂失明2，自己由幽暗之瞳免疫。
3. 精魂回合开始“安魂”正常回复玩家8（限一次），左4＋玩家左4＝8；失明使9点应有伤害减半向上取整为5，玩家9→4。
4. 精魂在上一回合已准备右2，玩家左4＋2＝6：幽暗之瞳使本击改暗蚀、伤害6+2=8，附腐朽2。
5. 精魂将运算左手调3，借玩家左6＝9；腐朽令回复0，失明自然计时结束，右手调3。
6. 玩家右6＋精魂右3＝9，正常回复9，生命4→13；之后进入实战。

**关键实现边界**：首次致命示范必须真正触发被动，不能被操演护持先截成1。仅该个确定的单段钝击窗口暂停玩家护持，并断言坟冢之力未消耗、无盾／亲和／形态等干扰；触发后恢复护持。失败应作为测试错误处理，不伪造技能发动。

此课精魂另有一次“回廊重赋”：进入实战整备时返还坟冢之力一次，以免玩家刚学会的每局一次能力在实战不可用；作为可见NPC技能在徽记及一条指引说明。它不修改术士在普通对战的规则，重试快照不再额外叠次数。实战精魂改为暗蚀攻击，玩家保留4／6后演算得到的实际手值与正常治疗结果。

## 八战：万象相生

狂野魔法起手1／2，元素回响32生命、0／0、普通近钝远刺。首轮NPC通过“映照”确定随后要显现的术式；这是教学专属能力，实战不再映照。类型只在正式攻击段消耗，纯运算、闪避选择和动画预览不推进队列。

为保证真实反应，按下表在回响自己的合法行动前用“刻印”清除已完成观察的上一例负面并附自身前置状态，再让玩家通过4／6交替攻击命中；不是在攻击结算后直接调用反应函数。冻结必须真实经过不能行动的回合，眩晕必须实际产生受限运算并自然到期，恢复可行动后才刻印下一组。每组末至多一次整备（清理已观察的自身负面、回复16），整课最多7次，不覆写玩家手值。

| 演示组 | 回响攻击前的自身状态 | 玩家固定类型队列 | 必须观察的真实结果 |
|---|---|---|---|
| A | 残响2 | 雷鸣 | 清残响、眩晕2，一次运算失效 |
| B | 先残响2，后感电2 | 闪电、雷鸣 | 各刷新旧状态为2并附耳鸣2；耳鸣受伤×1.5、不能盾／回血、免雷鸣 |
| C | 先覆霜2，后潮湿2 | 寒冷、寒冷 | 分别清前置状态并附冻结2，实际无法行动 |
| D | 先冻结2，恢复后再刻燃烧2 | 寒冷、寒冷 | 先×1.5保留冻结，再×1.5清燃烧；两击都不另附覆霜 |
| E | 先覆霜2，再潮湿2，最后油腻2 | 火焰、火焰、火焰 | 前两次×1.5并清前置、不附燃烧；油腻分支×1.5清油腻，照常附燃烧 |
| F | 潮湿2 | 闪电 | ×1.5，保留潮湿且附感电，观察邻接波及 |
| G | 先中毒1，后强酸1 | 强酸、毒素 | 新附对应状态，并把原状态刷新到2；不额外增伤 |

共13次指定类型命中，覆盖11类反应及覆霜／潮湿两个同规则入口。D的燃烧前置必须等冻结自然结束；E／F／G换组或同组换例前只清已观察状态，不能让上组耳鸣免雷鸣破坏本组结果。B的两次雷电互换之间先观察耳鸣的回血限制与感电增伤，再观摩到回响合法使用下一次刻印、清掉耳鸣；不能带着雷鸣免疫直接做第二次雷鸣反应。刻印最多13次，每例一次；整备仍另限7次。

固定4／6交替只是求当前合法加数的目标，不直接改玩家手。全部流程目标25轮内、预算上限30轮，超出先精简无关准备动作，不跳过状态自然计时。

狂野魔法当前映射可取每区间首值：雷鸣0、强酸8、毒素16、火焰40、寒冷48、闪电56；准备命中按上述队列选值。若存在多段，每段读取同一步声明的类型，不因预览重掷；本课不额外引入多段攻击教学。实战必须还原正常每类型8%、合计80%，其余20%普通；离开、重试、异常收尾也必须释放覆盖。

## 九战：光、力与心念

塑能学派起手1／2，对手为三相回响30生命，教学初始0／0、无盾；不同对照节点在它自己的回合“换相”，切至下次演示武装，实战配置见课表。

1. 算出攻击数字，选放弃攻击并存光耀；回响用普通光耀攻击，待用光耀抗性减伤且命中负面时长−1；玩家下一次攻击释放光耀，目标附目盲。
2. 算出攻击数字，存力场；回响用架盾形成5盾并公开令防御+3，然后玩家下一次力场命中，验证穿盾、无视正防、没有元素负面。
3. 算出攻击数字，存心灵；回响只做物理准备，不在此给玩家先挂会中断释放的控制；玩家心灵命中后看实际恐慌／震慑分支及一次受限行动。

不要求刷出两种心灵分支，不临时给塑能附目盲免疫。光耀部分只验证目盲附加及借数合法提示，不为了在一对一里虚构远处第三只手。法术塑形的放弃／不发动按钮始终同时显示，按步骤高亮；待用抗性只在消费前存在，力场不是“所有魔法都能穿盾”。

进入实战回响恢复30生命、防+1、光耀武装、3／5完整盾；玩家可自由选择所有十种魔法类型，不再强制前三个。

## 终战：万象回响

从全部术士子职中选角，真实经典1d20先攻；不启用护持、固定类型或教学调律。

- 万象回响：44生命，攻+1／防0，距离∞，默认近钝击远穿刺；无永久类型免疫或全控制免疫。
- **轮转术式**：每第二次普通攻击依次改为火焰、寒冷、闪电、雷鸣、强酸，奇数次仍普通；序列公开，正常附状态，不加特殊额外伤害。
- **折光外壳**：第三个自身回合结束后、之后每三个自身回合，按火焰→寒冷→毒素→强酸→闪电→雷鸣→光耀→暗蚀→心灵→力场循环获得一种一次免疫，立刻显示；所有临时亲和仍在一次攻击落地后消耗，不连续锁死固定属性的龙族。
- 不读取玩家龙族选择决定免疫，不因当前最优克制而临时改序；控制、腐朽、失明及盾牌照常生效，坟冢之力仍可救命。

这是章内最高生命、正攻击及双能力的拟定强敌；实际难度必须用四个术士子职逐一验证，不能凭配置宣称胜率已平衡。若龙族任一合法元素形成无法合理获胜的局面，先下调生命／免疫频率，不删该子职或偷偷改其攻击属性。
