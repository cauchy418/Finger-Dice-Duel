| 章 | 地点 | 可见关号 | 主题 |

新第二章九节教学依次为雷鸣、闪电、火焰、寒冷、毒素、强酸、暗蚀、元素反应、光耀／力场／心灵；第十战自选全部四个术士子职。用户已确认高塔空缺关补入剑咏者，仍保留十关。

每关仍先指导、再实战获胜通关。新版明确增加一次中央过渡提示，敌方按公开实战配置恢复；失败可重新指引或直接再次试炼。此规则取代v2的“敌方只治疗12、不清负面”切换方式；具体边界以共同流程为准。

## 文案约束

教学对话每关上限10句，NPC技能介绍计入；剧情、按钮标签、战报与徽记悬停说明单独承载。不得通过一条超长段落塞十几个指令规避句数限制，复杂反应采用同一条短提示伴随连续实操，完整数值表放在手册／徽记。教学句不写建局、快照、脚本、存档或“没有替你获胜”等设计说明。

本稿的技能、反应口径对照当前CharacterSkillText、StatusNames、GuideSheets与角色逻辑。40关已通过控制器实战与重试流程验证；难度仍需真人试玩，不沿用旧胜率证明新版平衡，本轮未重采胜率。

第一章初战改为剧情专用重甲战士（攻+2／防+2，无特殊技能），不再使用勇士；次战继续勇士精通重击教学，见[初战修订](chapter-01-and-04.md)。
