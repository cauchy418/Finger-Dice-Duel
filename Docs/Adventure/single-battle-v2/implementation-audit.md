现有第二、三章Sample保存函数会在独立试验通过时存子进度；不能仅把按钮字样改成“继续战斗”，后台仍重新Create。代码和对象生命周期必须一起修改。

## 实现顺序

1. 先建立同场阶段状态：`Guide / FreeCombat / Finished`，与既有战斗选择阶段分开；教学点由真实事件确认，不根据猜测的剩余血量判完成。
2. 用关卡NPC能力实现护持、调律、有限整备与号角，分别有来源、时点、次数、日志和禁用条件；不用全场Reset伪装技能。
3. 第一章先打通教学转自由、石头推障、状态与数值保留，再迁移第二章；第三章保留同一队伍、尸体、座位与额外行动。
4. 接通真实胜负存档、旧整关记录兼容、退出／主动重试清理；替换旧样本目录和结果按钮。
5. 制作／复用NPC徽记，统一全部人物按钮映射；复用现有技能、状态及补给动画并保存实际效果截图。

## 不能省略的验证

- 每关进入到结果期间，正常流程的GameManager、角色、手、队友关系和棋盘引用保持；只有主动重试可以建立新局。
- 教学完成时不写通关、不弹结果、不重置血量／手值／成长／记录／状态／轮次／播放队列。号角只有明示的回复，腐朽下回复0，不是强行回满。
- 自由AI确实可以攻击、合盾、回复和使用有限技能；没有残留白名单、固定目标、NPC无条件休整或人类代答AI请求。
- 证明所有教案校准都只改NPC的指定合法手；玩家新的手值来自正常运算。完整盾不会被SetValue无声抹掉。
- 第12课覆盖十类型、三反应与待用抗性，并在30轮教学预算内结束；随机分支看实际事件，不靠刷新重掷。
- 第13课保留换位后的座位与本轮旧／下轮新行动顺序；第16课尸体留场换手，不复活、不提前判胜；第19课羊血池真实打空，溢伤不二次算防御。
- 第24课同一奉献同袍从头到尾，AI援护后盾碎真实产生卫护斩；第27课攻防逐步增长再衰减，不使用预置成长；第28课同一仇敌标记迁移与真实死亡。
- 第29课全程同一奉献之誓；普通8击杀触发奖励，两次额外行动真实用完，死亡收缩距离与队友／对手人数正确更新。
- 1／2／4倍速、跳过动画、连续技能、输入恢复和终局留场正常；号角／补给不会覆盖最后一次伤害画面。
- 各终战按全部合法子职测试，复用共享种子采样再真人试玩；报告最弱子职与中止率。新值实施前的旧胜率只作历史对照。
