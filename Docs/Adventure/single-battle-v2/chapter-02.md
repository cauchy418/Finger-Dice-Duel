## 11 初战：剑上的法术

1. 完整5＋护卫1＝6，先碎盾选择火焰，再确定攻击目标；即时6伤，护卫28→22。
2. 护卫1＋己右2＝3，无攻击；真实经过自身回合末燃烧，22→19。
3. 观察完成后护卫公开用一次符文换装，将自己的攻击改为光耀；调律为一次普通4攻击提供合法加数，不改玩家手。玩家不在这次攻击前重新合盾，真实受光耀及目盲。
4. 玩家在真实受伤请求选择记录光耀，再通过普通运算打出4／6／8，将这一击改为光耀；待用类型消费，护卫受目盲。提示这不是圣光。

号角后保持当前双方手值、盾和目盲，护卫公开切为火焰武装并进入自由AI。玩家可再碎盾／受击记录，真实获胜才过关；易伤／免疫对照留给四战，减少重复准备。

## 12 次战：十种术式与三种反应

**始终同一名32生命调律护卫。** 玩家1／2、护卫3／2开场；不生成十三个独立开场，也不每段把玩家设回1／2。

准备新类型时，先用当前手与护卫调律后的加数真实算出攻击数字，选择放弃攻击并选择类型；下次正常攻击消费待用类型。每次人工选择两个相反选项均显示，只高亮本步需要的项。护卫只校准自己的手，玩家数字一直由真实运算积累。

| 同场顺序 | 必须看见的真实事件 | 下一段怎样接续 |
|---|---|---|
| 火焰与待用抗性 | 先存火焰；护卫真实火焰攻击时，待用火抗减伤且负面时长−1；之后玩家真正释放火焰，火抗随待用类型消费；观察燃烧 | 净化已观察的护卫燃烧，再继续，不清玩家资源 |
| 寒冷 | 首次寒冷附覆霜，护卫正常运算结果受影响 | 保留覆霜的真实计时 |
| 冻结反应 | 再次存寒冷期间让覆霜自然转潮湿；寒冷击覆霜／潮湿均可触发冻结 | 玩家按教案观摩，护卫真实经过两个不能行动的自身回合；不能立即清状态跳去下一篇 |
| 火焰反应 | 护卫恢复后用“注水铭刻”给自己潮湿2；玩家真实火焰命中，清潮湿、伤害×1.5、不附燃烧 | 同一护卫继续；只给下次反应补所需潮湿 |
| 闪电与导电 | 再次公开注水，闪电对潮湿×1.5、潮湿保留且附感电；观察回合开始邻接波及 | 感电按真实时点触发，不把伤害伪造成护卫普通攻击 |
| 雷鸣 | 附残响，观察其攻击范围限制 | 相邻1v1未改变合法目标时，用示意旁白说明，不虚构被挡的远处目标 |
| 强酸 | 附强酸后防御降低，查看下一击与属性栏 | 已观察后才允许护卫整备清酸，不能让后面的6伤继续按防0硬算 |
| 毒素 | 中毒在回合开始扣体力 | 经真实回合触发后才净化 |
| 光耀 | 附目盲，借数限制为距离1 | 仍可借当前相邻角色，不能误说完全不能运算 |
| 暗蚀 | 腐朽后护卫真实算9，实际回复0 | 不能在9之前整备净化；失败的回复也进入记录 |
| 心灵 | 看见实际随机恐慌／震慑及一次受约束行动 | 按实际分支解释，两个分支任一均完成观察，不要求刷到指定随机结果 |
| 力场 | 实际力场攻击、无额外元素负面 | 完成本课类型清单，穿盾在三战深入讲 |

这一路径覆盖十种魔法类型及冻结／火打潮湿／电打潮湿三种反应，复用寒冷、火焰、闪电的基础观察，**最少12次类型攻击**，不把导电再重复打一遍基础闪电。准备、状态观察也都走真实回合；教学预算最多30轮，预计12～18分钟。

护卫训练整备最多4次，每次净化已完成观察的自身负面并正常回复16。注水铭刻最多2次，只附潮湿，不附其他状态、不改手值或生命。它们只为连续试验续航，均有实际技能提示和次数；不能逐次给自己回满32。若腐朽等暂时阻止回复，先完成该状态观察并正常净化，再消耗回复次数。

全部观察完成后触发号角，固定火焰武装，关闭校准／注水／整备，转正常自由战。守关者仍是原护卫；状态、当前血量和玩家待用类型保留。酸毒互相刷新、雷鸣叠残响、油腻反应等放在指引复习页，不再额外创建可选试验场景。

## 14 四战：先抗性，再屏障

同一32生命调律护卫、玩家1／3、护卫1／3。采用六段连续观察，不再对每种属性分别建局。

2. 护卫调律给出当前玩家算4的合法加数，玩家放弃攻击存4屏障。再受6：7→抗性4→屏障0；屏障整池归0，持续抗性仍在。普通盾、奥术守御不得混称。
3. 再算2，将持续抗性改授护卫、类型火焰：自己的旧物理撤销，护卫得到来源明确的持续火抗。随后一次普通挥砍真实不再减半。检查菜单仍只有物理整组与五元素，不能出现另五种魔法抗性。

5. 为观察四次而不把玩家耗死，护卫可用两次**稳息术**：在上一段燃烧已经真实触发后，净化该已观察燃烧并回复玩家8，其他正面状态／屏障／技能来源保留。不是把双方设回20，战报注明实际回复；仍有正常9回复可用于准备。
