# 连续战斗的共同规则

**状态：已接入连续战斗版。** 适用第一章1～9、第二章11～19、第三章21～29；第五战的教学发生在真实先攻页，开战即自由实战，不启用下述操演保护。终战10／20／30没有保护、校准或教学补给。

## 一局里的四个阶段

| 阶段 | 行为 | 能否记通关 |
|---|---|---|
| 开场 | 一次创建角色、队伍、座位、起手、伤势及NPC技能；公开配置 | 否 |
| 引导 | 按真实行动观察教学点；必要时NPC使用公开的调律或整备技能 | 否 |
| 自主 | 教学完成后，在安全结算边界解除白名单和脚本；原地使用正常AI继续 | 否，直到实际胜利 |
| 结果 | 胜负确定、全部动画和待答结束，留场显示“试炼结束” | 仅满足教学要求的真实胜利 |

切换指引不调用建局、全体Reset、清空记录、重排座位、重掷先攻或整体重置生命／手值／状态／技能。成长、预兆、抗性来源、护盾、变形血池、死人、阵营关系、轮次和额外行动队列都继续保留。

经典课与终战的选角／先攻页仍正常存在，它们是开战前配置，不是第二场战斗。预览使用定义数据，真实参与角色只创建一次；完成投骰后初始化并开始这一局，不能先打一回合再以先攻结果重建。三章使用不同背景、不同关卡主动重试仍各自是新局，不要求整章十战连成一场。

教学完成也不强行轮到玩家。当前回合、嵌套反击、援护、死亡选择、额外行动和状态收尾全部正常完成，再切换控制策略；从真实的下一行动者继续。不要为“进入自由阶段”额外推进或跳过一个回合。

## 公开的操演工具

这些是关卡NPC的技能，不加入可玩角色或竞技规则。名字、作用对象、实际变化、剩余次数都进入战报；不以场景刷新替代技能。完整定义见[NPC表](npcs.md)。

1. **操演护持**：仅引导期保护玩家、同袍及指定守关者的原形生命，致命伤时最低留1。被指定为死亡教学对象的单位不受此保护。羊血池照常破裂，角色实际承伤与溢伤照常结算。它不是格挡、抗性、免疫或闪避，不减少负面时长；若保护介入须明确显示“操演护持”，不能仍声称打出了完整扣血数字。教案正常路线应尽量不触发兜底。
2. **演练调律**：在施训者自己的真实回合开始、正常行动前，按当前检查点公开调整自己一只或两只可用、无完整盾的手为1～9。只改这些手，不触发攻击／回复／合盾；不改玩家数字。需要新的玩家手值时，提供可借加数，让玩家通过真实运算取得。不能越过冻结／锁定等限制，不能覆盖完整盾；先按正常行动破盾，再安排后续调律。
3. **整备术／换装**：只在教案注明的节点净化指定已观察的负面、回复有限生命或改变NPC武装／试验修正。每次公开，不清玩家预兆、永久成长、其他来源抗性或全场状态。冻结期间不能为下一段偷偷解冻；先真实经过跳过与计时。
4. **实战号角**：教学全部完成、待答与动画结束后，守关者一次性尝试回复12生命，玩家和存活同袍各回复6；均受正常上限、腐朽及治疗规则约束，不净化、不回满、不复活。之后解除操演护持和所有教学指令，进入自由阶段。若守关者暂处羊形态，则等本课规定的恢复观察完成后再号角。第五战、终战及已通关后直接自由练习不触发号角。

调律先根据**当前**手值、护盾、合法性与状态改算规则求出可用加数，不照抄旧独立样本的开场元组。凑不出所需条件时，安排真实的准备运算；不使用“清空玩家两手再设回1／2”的捷径。检查点只表示该观察已完成，不保存一套等待覆盖的战场快照。

需要保留手值、让对手再演示一回合时，使用明确的**关卡动作“观摩”**：仅在教案指定的引导步骤开放，消耗本次正常行动，保留手值并走正常回合末计时，不触发运算技能或获得气。不把它冒充公共“跳过回合”；普通规则不满足跳过条件时，不能凭空点普通跳过。冻结时仍走既有冻结跳过，技能／防守待答期间不能观摩。自主阶段关闭此教学动作。

## 引导结束后的对手

取消脚本休整、固定目标与强制答案，绑定正常AI和对应NPC策略。NPC可以攻击、合盾、回复、使用文档中的有限技能，玩家可以失败。NPC自己的负面状态、现有伤势、盾和技能冷却保留；刚施加的控制必须仍有价值。

普通AI不能继续使用教学专属调律／试验整备。自由阶段的架盾、急救等独立技能有明确行动成本、冷却和次数，不是无限恢复或每回合后台改数。队友AI不得攻击友军或把冲击、束缚、攻击转移误施给玩家；正常借用队友加数仍允许。

四、七战的石头仍是原来的场景对象，不占生命／行动／胜负。可用一次正常行动“推开路障”将一侧石头移到边缘，实际缩短该侧距离；不重建角色或场景。AI也可推障，不让自由阶段因永久超距形成死局。

## 通关、失败与存档

- 首次必修：`教学完成 && 实际胜方属于玩家一方`才写关卡完成。关卡目标列表打满不结束比赛；非终战的操演护持保证必要守关者不会提前被演示击杀。
- 单挑按真实赢家；2v2和八人按玩家队伍／阵营胜负。玩家死亡但同袍仍在时继续按公共规则进行，不能提前判整队失败。
- 沿用公共50轮规则，轮次不在教学结束时归零。到限实际判赢且教学完成可以过关；教学未完、平局或失败不写通关。长课的强制教学预算控制在30轮以内，至少留20轮自主实战；实施时如超预算先缩短重复准备，不偷偷延长规则。
- 保留所有旧整关与章节通关键，失败不删除旧胜利，不强迫已通关玩家重打解锁。旧Sample键作为旧记录保留，不再据它们生成新子局或授予新版整关胜利。
- 首版不新增半局存档。退出后重打从该课开场重新建立一局，事先提示；同场下一段不重建。后续若加继续半局，必须恢复完整战斗而非只保存指引序号。
- 已通关课可选择“直接自由练习”：仅跳过文字与演示，使用该课公开开场和自由AI，不领取号角补给、不临时捏造已完成的成长。终战仍真实投骰。

## 界面、动画与配乐

顶部为“引导3／6”或“自主战斗”，分段只更新现有指引。保留上一页／下一页／回到当前，翻文字不撤销战场。发动／不发动等正常选项全部显示，当前指定项高亮且仅其可点；进入自由阶段取消门禁。

不再出现“下一试验 · 重置场景”“重试本样本”或教学后“试炼完成”。取代为一条不遮挡战场的“教学结束，击败对手完成试炼”。右侧“试炼结束”只在真实终局且动画结算完成后出现。

NPC调律／补给用短技能表现和实际手值／血条变化；不播放重开场景动画。原背景、战报、角色引用和徽记映射保持。四人／八人指引不得挡手牌与技能选择。普通课持续用River at Battlefield；三章终战用Dawn of Steel，不因进入自主阶段重启音乐。半血鼓层沿用本局锁定状态，不在切段清零。
