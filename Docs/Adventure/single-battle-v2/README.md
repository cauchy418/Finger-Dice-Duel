2026-11-01，**已接入游戏，数值仍需试玩校准**。本稿按玩家本轮要求重写前三章；上一版逐关文档与验收记录保留为当前实现的对照，不代表本稿已经完成开发。

每关只建立一次战斗：**开场 → 同场分段教学 → 自主战斗 → 实际获胜通关**。前后使用同一批角色、同一座位环、同一份战斗记录。完成一段只更新指引，不弹“试炼完成”、不重建场景、不重新分配手值。只有主动重试才开始新的一局。

## 需要改变什么

- 第一章初战至四战的“安全收官”改为教学后正常AI；四、七战不能再凭一次命中或状态观察通关。六、八、九战提高对手续航，留出真实自由阶段。五战保留经典实战，终战提高配置。
- 第二章前九课不再调用“下一试验”创建新局。尤其十种术式、抗性对照、预言与幻术的分支，改为同一场内的章节指引。咒法与死灵课从开场就是四人配置，避免1v1讲完再换成四人。
- 第三章各段不再重新布置四／八人；同袍不换子职，成长不预置回旧数值，死亡不复活。第九课全程奉献之誓，以8的普通攻击展示击杀奖励。
- 三章非终战都要完成必修教学并取得真实胜利；终战从先攻后直接自由实战。教学完成只说明“接下来由你决定”，不能写通关键。

## 难度方向

玩家保留所选角色的正常20生命上限、攻防、距离与技能；开场伤势另行公开，不给全职业统一加攻防，以免遮蔽教学数值。主要调整NPC生命、有限续航与简单技能。

同章终战的主要对手拥有最高基础生命及更完整的战斗能力；不通过免控、偷偷重加抗性、读取玩家选择或无限回血制造难度。第三章八人关与终战人数不同，不能直接拿敌方总血量相加宣称难度；终战是否最难仍须在实施后按玩家队实际胜率与试玩校准。本稿数值是待验证的初稿，不沿用旧版采样作新版难度证明。
