# NPC、有限技能与徽记

**设计稿，待实现。** 下表只给冒险NPC追加能力；可玩子职保持现行规则。每课数值见章节，不把NPC假装成拥有相同徽记角色的完整技能。

## 教学通用工具

| 技能 | 类型与口径 | 自由阶段 |
|---|---|---|
| 操演护持 | 被动；仅保护关卡列出的玩家、同袍、守关者原形生命，最低1；临时教学标记常驻显示；指定受损侍从／前锋不受保护，可真实死亡 | 关闭 |
| 演练调律 | 主动；自己的回合开始时、普通行动前，按检查点调整自己1～2只可用无盾手为1～9；纯改数、显示旧值→新值；每节点一次，不抢回合 | 关闭 |
| 训练整备 | 主动；自己的真实回合开始时、普通行动前，仅净化教案列出的、已经完成观察的自身负面，回复16；每节点最多一次，整课上限见课表；不移除别人的技能资源 | 关闭，剩余次数不折成战斗回复 |
| 符文换装 | 主动；自己的回合开始时，切换已预告的攻击类型／试验属性；每节点一次，不叠加隐形加成 | 仅保留课表注明的固定武装，无教学任意换装 |
| 稳息术 | 第14课专用主动；自己回合开始时，净化玩家身上已完成观察的燃烧，正常回复8，整课最多2次；不改正面效果／屏障／抗性来源 | 关闭 |
| 实战号角 | 被动；本课教学完成且结算边界安全时仅一次，尝试自身回复12、玩家及存活同袍各回复6；不净化、不复活，腐朽等正常生效 | 结算后不再触发 |

“训练整备”不能在冻结等状态观察完成前清掉它，也不能改屏障、预兆或本课需要比较的持续抗性。魅惑、变形等仍按公共规则限制技能；教案选择其自然恢复后的合法窗口，不以NPC身份忽略控制。调律导致后续普通行动的结果仍受覆霜／潮湿等影响。

未在关卡写明的训练整备／稳息／试验铭刻次数均为0，不因出现在通用表就自动授予。调律只在明确的准备节点使用、每节点至多一次；辅助NPC也必须有对应配置。不能用“等待教学”反复触发这些技能刷血或重置正面资源。

## 自由战的简单技能

| 技能 | 完整定义 | 使用者 |
|---|---|---|
| 架盾 | 主动，代替本次正常行动；选自己一只可用且无完整盾的手，变为5并形成完整盾，正常通知合盾。使用后接下来的3个自身回合不能再用；不回复、不多攻击 | 课表指定的教官／盾卫；震慑仍可架盾，冻结等无法行动时不能架盾 |
| 军需急救 | 主动，代替正常行动；距离1内选择自己或一名存活队友回复4，整局最多2次、冷却3个自身回合；满血不使用、腐朽不浪费补给 | 非可玩子职的普通同袍；已有完整古贤／奉献子职的同袍不再额外叠此技能 |
| 稳弦 | 被动；普通运算结果为6、正常穿刺攻击时，本次基础伤害+1。多段只修正该次普通攻击，不把技能额外攻击再算一次 | 指定弩手；不穿盾、不附新状态 |
| 整军 | 主动，代替正常行动；首次生命不高于一半后可回复6，整局一次，正常治疗；不净化、不复活 | 第一章终战哨站骑士 |
| 汲能回路 | 保留原技能：每3次本人普通攻击实际造成生命伤害，按正常规则回复3并归零；多段最多记一次，持续／反弹不记，腐朽阻止回复；羊形态暂停 | 第二章终战法师幻影 |
| 集结令 | 主动，代替正常行动；首次不高于半血后，为自己及距离2内存活队友各回复4，整局一次；不净化、不回满、不复活 | 第三章终战残旗指挥官 |
| 推开路障 | 关卡动作，消耗一次正常行动；将一侧仍占位的石头推向场边，该侧空隙减1，立即按原角色顺序重算距离；不能在冻结／无法行动时用 | 第一章四、七战双方，教学完成后开放 |

各技能一次性计数和冷却贯穿整场，切段不刷新。NPC正常算出9仍按自己的普通规则回复；不会为了显得聪明偷偷多用一次技能。终战没有调律、护持、训练整备或号角。

“观摩”另属玩家教学关卡动作，仅在指定引导步骤消耗一次正常行动以保留手值、等待NPC演示。它不是新增通用跳过权限，不出现在自主战斗或竞技中；计时、待答限制等见[共同规则](common.md)。

## 终战配置与难度上限

| 章 | 非终战主要敌人生命上限 | 终战主要敌人 | 同场其他单位 |
|---|---|---|---|
| 边境哨站 | 最高36；自由阶段主要0／0或+1／0 | 哨站骑士40，攻+2／防+1、距2，挥砍；架盾、整军 | 玩家战士20 |
| 法师高塔 | 主要28～32；自由阶段主要0／0 | 法师幻影40，攻+1／防0、距∞，强酸；永久火／寒抗性与毒免，汲能回路 | 玩家法师20 |
| 残旗战场 | 四人课主要守关者最高32 | 指挥官36，攻+1／防+1、距2，挥砍；集结令 | 弩手28，攻+1／防0、距2，穿刺、稳弦；玩家20及古贤同袍20 |

这些是初稿，不声称强度已经验证。不得用对所有法师控制免疫、对破阵者破盾免疫、阻止援护／攻击转移、隐藏阶段复活来提高难度。测试若显示某合法子职无法合理取胜，优先调整生命、有限回复与AI，不删除刚教会的反制。

## 徽记与复用

继续复用老兵、奥法护卫、法师幻影、秘法典籍、旧骑士及各可玩子职徽记。受损侍从仍使用奥法护卫图案，另显示伤势／身份小标，不复制一套角色图鉴。
