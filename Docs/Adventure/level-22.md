# 第三章：残旗战场·次战 — 越过盾墙

2026-10-30，**设计待实现**，全局编号22。玩家为王冠之誓；两段独立演练，每段开场重新公开配置。[共同要求](chapter-03.md)。

## 演练一：借得到，不等于打得到

四席关系沿用初战。玩家1／2，攻+1／防−1／距1；同袍左3，教官甲、乙均20生命、防0。玩家左1+同袍左3=4，结果显示后查看目标：教官甲距离1可选，教官乙距离2不可选。只允许攻击教官甲，造成5伤害，20→15。

军士长：“你的手可以借到远处，兵器却仍有距离。不要把借数的范围当成攻击的范围。”

保留正常合法性显示，不宣称无近处敌人就能放弃攻击，因为队友也可能是合法攻击目标。

## 演练二：自己的盾碎，自己的距离成长

| 原席位 | 开场配置 |
|---|---|
| 1 玩家 | 20生命，左5为完整盾／右2，王冠初始攻击1、距离1 |
| 2 教官甲 | 20生命，3／4，攻0／防0、距1；先动 |
| 3 教官乙 | 20生命，3／4，攻0／防0、距1 |
| 4 同袍 | 20生命，3／7，攻0／防0、距1 |

1. 教官甲左3借同袍左3=6，攻击玩家。完整盾格挡，玩家不掉血，自己的盾破碎触发神圣誓忠：距离1→2，攻击1→2。
2. 其余NPC休整。明确这是真实破盾后的成长，不能在首次瞄准前偷偷加射程。
3. 玩家已破盾的左5借远处教官乙左3=8，距离2已可攻击教官乙，造成8+2=10，教官乙20→10。

旧盾已经破碎，再拿那个5运算不重复成长；队友的盾破碎不会提升玩家。本课不要求教主动消耗盾的所有分支，重点让玩家看到成长后第二次行动的射程。
