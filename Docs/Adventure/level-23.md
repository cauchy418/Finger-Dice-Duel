# 第三章：残旗战场·三战 — 盾锋与回响

2026-10-30，**已实现**，全局编号23。公开2v2，玩家席位1使用奉献之誓，20生命、攻0／防+1、距1，1／2；教官甲席位2为2／3、20生命、防0；教官乙席位3无干预；同袍席位4为3／1。其他单位无盾、无状态。[共同要求](chapter-03.md)。

军士长：“奉献之誓把4和6留作盾。你的盾落下时，也能把敌人震退；别再把它当作普通的4点攻击。”

## 连续流程

1. 玩家左1借同袍左3=4。手值先变4，并形成完整的**4盾**，不能画成5。被动“卫护斩”列人物目标，高亮邻近教官甲，固定冲击2，甲20→18。
2. 不出现普通4攻击的第二次选目标；同袍仍3。其他NPC按轮序休整。
3. 玩家完整左4盾借教官甲左2=6。旧4盾先破碎，选择卫护斩目标教官甲，18→16；再形成完整6盾，再选一次冲击教官甲，16→14。
4. 两次冲击各有可见提示与记录，不能合成一次4点普通攻击，也不能漏掉第二次目标选择。

冲击为固定2点，沿用它本身的盾／闪避等处理，不称“真实伤害”；本样本目标防0、无盾、无抗性，便于核算。冲击范围取玩家自己的当前攻击距离，不允许选距离2的教官乙。

## 完成与验收

玩家左6完整盾／右2、20生命；教官甲14生命。暂停后可看见4盾、破盾及6盾的完整过程，再点“试炼结束”。援护等不相关窗口不主动触发；若显示相反选项，保留显示并按教学门禁禁用，不能隐藏正常选项。
