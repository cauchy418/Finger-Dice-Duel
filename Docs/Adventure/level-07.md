# 第一章：边境哨站·七战 — 卓越战技与四种状态

## 目标与配置

玩家战士·战斗大师，攻防0/0、射程2，左1右4。教官40生命、攻防0/0、训练射程2，左2右3；两侧石头占位，双方距离2，用以直观看到跛脚把射程2减至1。教官无角色技能，生命与射程为开场公开的训练配置。

## 连续演算与选择

1. 己左1＋教官右3＝4，另一手4；招式面板选流血。造成4伤，教官回合开始再失去1生命，攻防−1；教官右3＋己左4＝7。
2. 己左4＋教官左2＝6，另一手4；选跛脚。此击受仍存在的流血防−1影响；教官射程2→1，无法攻击距离2的玩家。教官右7＋己右4＝11→1。
3. 己右4＋教官左2＝6，另一手6；选震慑。教官左2＋己左6＝8，但不能攻击，自动放弃攻击而保留8，不把震慑误说成不能行动。
4. 己左6＋教官左8＝14→4，另一手6；选倒伏。倒伏在此击造成伤害后附加，不放大施加它的这一击。教官休整。
5. 己右6＋教官左8＝14→4，另一手4；选“不附加”，以倒伏受到伤害×1.5展示4→6。此击完成教学目标，显示“训练完成”，教官可以仍存活，不伪造击杀。

每种招式必须经绘画图标按钮选择；其它选项在本拍不可选，最后一击必须拒绝附加，避免新状态混淆数值。只在实际伤害>0时附加，均持续目标自己的2回合；被盾挡、闪避、取消不附加。流血消退时攻防恢复，跛脚射程到期恢复；旁白与状态栏/战报同源。
