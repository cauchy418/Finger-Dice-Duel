# 第二章：法师高塔·八战 — 镜中的数字

2026-10-27更新，已实现，全局编号18。玩家法师·幻术学派，20生命、攻0／防−1、距离∞；护卫20生命、攻防0／0、普通钝击。镜像错位改为主动选择，不再投50%随机数。

典籍：“先看清它要用哪只手，再决定借给它哪一个数字。”

## A：发动，替换加数

玩家2/4，护卫2/5，护卫先行。护卫准备以左手2触碰玩家右手4；运算尚未发生，先显示双方手名与数值。发动／不发动均显示，本样本只高亮并允许点击发动。

发动后改用玩家左2，护卫2+2=4，玩家不发动后续镜像折光，受5伤，20→15。选择本身不改变玩家的2/4，也不消耗额外回合。

## B：不发动，保留加数

独立子局使用相同起手和护卫意图；两个选项仍显示，只高亮并允许不发动。保留玩家右4，护卫2+4=6；后续镜像折光不发动，玩家受7伤，20→13。

复习：持有2即可保护自己任意一只被借用的手，不要求原加数本身为2。另一手必须是合法加数；自加、偷窃和预言压制不触发。每次触碰只询问一次，刷新、确认攻击目标与实际结算不重复询问。额外纯运算也须询问；巨龙座两次加数分别询问，第二次显示中间手值。

## C：镜像折光，整次减半

玩家3/5、护卫3/1。玩家没有2，不触发错位；护卫左3+己右5=8，攻防修正后原为9伤。

按典籍选择小手变2减半，自动把较小手3改2，整次伤害减半向上取整9→5，玩家20→15。不再要求挑手。小手本来已是2时，只要双手差2仍可发动；固定伤害等可否减免沿用原规则。
