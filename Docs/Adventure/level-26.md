# 第三章：残旗战场·六战 — 借敌之盾

2026-10-30，**设计待实现**，全局编号26。公开2v2，玩家1为破誓者，20生命、攻+2／防0／距1；同袍4，敌人2／3。[共同要求](chapter-03.md)。

## 一：5成为攻击

玩家1／2，同袍左4，教官甲20生命、防0。玩家左1借同袍左4=5，“恐惧打击”将5改为基础5攻击，选择邻近甲，造成5+2=7，甲20→13。玩家左手仍为5，但没有形成盾牌。

军士长：“同样是5，破誓者拿它进攻。不要只看数字，还要看持有者的誓言。”

## 二：转移到另一名持盾者

重建玩家5／2、无盾；教官甲席位2左2／右5完整盾，教官乙席位3左5完整盾／右1；同袍席位4左5完整盾／右1、12生命。甲、乙20生命，攻0／防0。

教官甲先动：左2借玩家右2=4，攻击玩家。玩家持5，触发“憎恨灵光”；正常保留发动／不发动，只高亮发动。角色候选中高亮教官乙并转移整次攻击。乙的盾格挡，盾碎、生命仍20；玩家仍20，同袍仍12，玩家的5不被消耗。

乙距离玩家2，仍可作为这个技能的转移目标；这不扩大破誓者普通攻击的距离。玩家本人及原攻击者甲不可选，甲即使也有盾仍不合法；同袍有盾，通常可以转移给他，教程禁用该错误选择并解释误伤。

## 完成与验收

人物目标只列角色，不列“角色·手”；正确展示教官甲、乙与同袍的徽记，不能因NPC名字找不到资源而出现白块。验证实际目标、格挡与日志归属一致，无重复扣原目标生命。技能标题采用规范名，不继续用“攻击转移”作为正式技能名。结束后留在战场，点击“试炼结束”。
