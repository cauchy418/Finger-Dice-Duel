# 第二章：法师高塔·次战 — 十种术式

2026-10-26，**已实现**，全局编号12。玩家法师·塑能学派，20生命、攻0／防−1、距离∞。采用分篇实验与断点，预计12～18分钟，可分次完成。

## 分篇与共同演算

典籍：“伤害的大小写在数字里，伤害的性质藏在颜色和图案里。记住一种，再翻下一页。”

三篇必修：五元素、五奥术、三种核心反应。每个样本均独立建局，开场公开重置；完成后“下一试验”或回目录，回看文字不重算当前攻击。

十类型统一起手：玩家左1右2，护卫左3右2；双方20生命，护卫攻防0／0，无盾与修正。

1. 己左1+护卫左3=4，选“放弃攻击”，再选该类型；本回合不造成伤害。
2. 护卫左3+己左4=7，无效果。
3. 己左4+护卫右2=6，选择照常攻击及护卫，消费待用类型。没有其它修正时造成6伤，护卫20→14。
4. 暂停说明；要看持续效果的样本，再按标注推进护卫一个自身回合。不能自动替玩家回答技能选择。

## 十种魔法伤害必修

| 样本键／类型 | 展示结果 | 区别 |
|---|---|---|
| fire／火焰 | 燃烧2回合；护卫回合末再受3点，14→11 | 不是穿盾攻击 |
| cold／寒冷 | 覆霜，后续结果减半至少1，到期转潮湿 | 初次不是冻结 |
| lightning／闪电 | 感电，下个回合开始自己及相邻角色各受1闪电 | 本样本玩家也受波及，不只敌人掉血 |
| thunder／雷鸣 | 残响，只能攻击距自己1的角色 | 与限制借手距离的目盲分开 |
| acid／强酸 | 本击后防御−2 | 后续攻击利用降防，不多算本击2伤 |
| poison／毒素 | 中毒，下个回合开始受2，14→12 | 不走盾与抗性，仍可受同型免疫／易伤影响 |
| radiant／光耀 | 目盲，借手只限距离1 | 不附圣光，不额外净化／减疗 |
| necrotic／暗蚀 | 腐朽；护卫随后尝试9，14→14 | 9仍是回复，只是被阻止 |
| psychic／心灵 | 随机恐慌或震慑 | 恐慌攻−2且不能打来源；震慑不能攻击但可运算。固定种子回放一个分支，对照页写另一个，不伪称必定某种 |
| force／力场 | 6点力场，无附加状态 | 三战再深入穿盾与正防御 |

覆霜样本追加护卫右2+己左6=8，覆霜改为4；须承受这次小额攻击并显示玩家防−1，不能描述成护卫被冻住。暗蚀样本追加护卫左7+己右2=9，真实回复0。

持续效果在真实自身回合入口／出口推进；其余样本可休整观察。雷鸣与光耀的距离区别附可回看的座位示意，不加入随机进攻的围观单位干扰数值。

## 三种必修反应

仍须先真实放弃一次攻击、选择类型，再打下一击。护卫开场带2回合已有状态，中间休整后保留1回合，玩家不带状态。

| 键 | 已有状态＋攻击 | 结果 |
|---|---|---|
| freeze | 覆霜＋寒冷 | 清覆霜／潮湿，冻结2回合；护卫不能行动，使用跳过出口，不误判失败／游戏结束 |
| melt | 潮湿＋火焰 | 6×1.5=9，清覆霜／潮湿，本次不附燃烧 |
| conduct | 潮湿＋闪电 | 6×1.5=9，保留潮湿，照常附感电；后续波及照常 |

**不可沿用基础样本的护卫3+4=7**：覆霜／潮湿会改这个结果。反应样本护卫明确“休整，保持实验状态”，不暗改手；玩家仍用1+3→4铺设、4+2→6攻击。

## 可选实验与复习

- 强酸击中毒：附强酸、中毒刷至2；毒素击强酸：附中毒、强酸刷至2。均不额外增伤，保留原状态来源。
- 雷鸣击残响：清残响、附眩晕；不混成震慑或冻结。
- 火焰击油腻：清油腻、伤害×1.5，仍附燃烧；不与同目标潮湿再叠倍率。
- 独立有盾反例：普通元素盾挡伤仍算命中、可挂状态；闪避／取消则不挂。不改十类型的基准样本。

## 完成与验收

10种类型实际攻击，以及freeze／melt／conduct完成才记“试炼完成”。不要求一局连续打13种攻击，不要求等持续伤害杀死护卫；可选实验不挡通关。

结语：“颜色不是装饰。下一次看见一道光，先问它是什么，再问它有多大。”结算用“十种伤害／三种反应／全部反应”分页，不塞一屏长墙。

验收铺设不伤害、下一击消费、光耀／圣光、恐慌／震慑命名，感电双向波及，冻结跳过不结束游戏，已有状态在休整后仍在，修正不污染6→9，样本断点与退出不重复消费旧答案。
