# 角色技能与持续状态动画现行清单

按 `CharacterDefinition.BuiltIn` 全名单、现行技能实现、语义事件注册表和生产播放器复核。规则数量与数值以 [RULES](../RULES.md) 为准。旧版55子职建议清单已下线，可从 git 历史取回。

本轮修复的是改版技能缺失入口、错用通用状态放大、资源增减不可区分和手部落点错误；其他角色复用现有专属或基础动作。本轮17名角色补齐／更新，41名核对沿用，共58名角色且无重复。逐角色“沿用”表示路线与现行规则相符，不表示本轮为该角色重新制作了每个镜头。共享攻击、盾变化、闪避、反击、移位和面板快照继续覆盖实际结算。

新定稿与截图见[本轮接入验收](../Art/Integration/skill-animation-rework/README.md)，已有形态／孢子／幽影定稿见[既有接入验收](../Art/Integration/skill-animation-update/README.md)。

## 持续表现

所有现存状态／资源都由 `CombatStatusIcons` → 不可变 `CombatVisualFrame` → `CombatStatusMotion` 驱动。图标与剩余回合／层数始终可读；每位角色最多同时显示三组环境效果，按组轮换；新增、刷新、变化短闪，移除淡出，死亡清除。通用循环是已实现的共享表现，不声称所有旧状态都有独立设计的完整循环。

| 当前专属补齐 | 常驻与变化 |
|---|---|
| 知识祝福 | 金色能量环、最多六个可视层点；真实层数始终由图标角标显示，不随回合倒计时；消费另播旧层数→0，闪避／取消也显示实际消费。 |
| 困惑 | 紫色符文逆向交错运动；成功附加与进位结果改1分开，运算显示真实和→1。 |
| 圣火 | 金色火环缓慢旋转，和红色灼伤区别；命中／治疗附加、穿透免疫另用独立镜头。清掉的状态随快照淡出。 |
| 灼伤 | 红色余烬向上漂移；回复后的实际火焰伤害单独显示，不冒充治疗量。 |
| 兽性之魂 | 实际层数图标常驻；积累和消费成长分开，不再把积累总数当作永久攻防增长。 |

失明暗环、孢子生命、剑歌、醉拳、气、逸闻记录与类型保护沿用现有细化；其余状态沿用对应元素／状态族的轻量循环及图标呼吸。所有动画只读取结算数据，不改变血量、手值、随机数或技能生效条件。
