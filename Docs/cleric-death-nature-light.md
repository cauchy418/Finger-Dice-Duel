# 牧师：死亡、自然与光明领域

现行角色池为12职业、62子职，牧师9领域；守序20／中立22／混乱20，共611种合法无序双将。`StatusEffect`有32个非空状态值；规则分类为25种负面状态（含物理易伤）和9种角色状态，其中剑歌、醉拳由独立技能状态维护，不占枚举值。手册将物理易伤放在伤害修正页。

三名牧师均为20点体力、攻0／防−1、距离∞，共同回复数字可以选择自己或其他存活角色。死亡与自然的普通攻击为距离1以内钝击、超过1穿刺；光明的攻击为光耀。

| 子职 | 稳定ID | 阵营 |
|---|---|---|
| 死亡领域 Death Domain | `cleric_death_domain` | 中立邪恶 |
| 自然领域 Nature Domain | `cleric_nature_domain` | 中立善良 |
| 光明领域 Light Domain | `cleric_light_domain` | 守序善良 |
| 净化领域 Purification Domain | `cleric_purification_domain` | 中立善良 |

光明与净化是两个独立子职。净化继续使用固定5点火焰、圣火与灼伤；旧净化曾沿用`cleric_light_domain`，现已迁移至`cleric_purification_domain`。现行`cleric_light_domain`只指光明领域。

## 死亡之触与假死

**死亡之触｜被动技能**：普通运算可以选择其他已死亡或假死角色的本体手作为加数。死者保留死亡时的手值；先点击自己的运算手，再点击死者或假死者的合法手牌，不增加逐手列表。只改变自己的运算手；只有借用这类加数所产生的本次攻击改为暗蚀。借普通存活角色的手仍为近钝击、远穿刺。

死者只能作加数，不能作为攻击或治疗目标；由死者加数算出攻击后，另选一名合法存活目标。其他角色不能借假死者的手。变羊或荒野形态暂停原角色技能时，不能发动死亡之触。

**死亡赐福｜主动技能**：自己回复结束后，可以通过统一角色选择按钮令本次受疗者假死2回合；也可不发动。

**假死｜角色状态**：不算死亡，继续占位、计距、轮转并参与胜负判断。持续目标自己的2个回合，重复附加刷新；期间13类抗性持续生效，不因受击消耗，抗性仍按公共规则减伤与减少攻击附加负面时长。受伤、付生命或直接改生命均至少保留1点；假死结束后解除这部分抗性与生命下限。

假死者自己的运算仅改变手值，不攻击、治疗、合盾，也不触发本次运算的其他技能效果。圣火立即清除并阻止假死；已有持续伤害和状态计时照常处理。

## 自然赐福与抑制元素

**自然赐福｜被动技能**：自己回复结束后，受疗者自动获得自然祝福2回合。

**自然祝福｜角色状态**：任何持有者受到一整次未取消攻击后，使实际攻击来源束缚2回合。闪避、盾挡、零伤害均触发；同一整次多段攻击只触发一次，取消不触发。反施的束缚是独立触发，不按来袭攻击的格挡或抗性扣时长。知识祝福的附属力场伤害不重复计作新发起的一整次攻击。祝福不叠加，重复获得刷新；圣火清除并阻止。

**抑制元素｜被动技能**：自然领域受到强酸、寒冷、火焰、闪电或雷鸣攻击时，阻止该类型的基础负面状态和由该类型触发的元素反应，不减免其攻击伤害，也不阻止独立的流血、战技等技能附加。基础状态对应为强酸／覆霜／燃烧／感电／残响。

同时储存对应基础状态，供自己的下一次攻击附加，基础时长2回合。新储存覆盖旧储存，不叠加；下一次攻击发起时消费，即使随后闪避或取消也消费。附加状态按该次攻击每个命中段的格挡、抗性与免疫规则处理，不改变攻击的伤害类型。储存由攻击上下文快照维持，多段中途新获得的储存留给再下一次攻击；只做预览或AI估值不会消耗储存。

## 光明修行、黎明曙光与光明赐福

**光明修行｜子职**：攻击为光耀，命中附加目盲，基础时长2回合。

**黎明曙光｜主动技能**：每段攻击命中目标后，可以清除目标全部负面状态，每清除一种，令本段伤害+2。先清除，再附加本段新目盲；前段留下的目盲可参与后段的独立选择。闪避、取消没有选择；盾挡算命中，可以清除状态，但盾仍可挡下伤害。人类选择完成前暂停本段伤害与原回合收尾，不提前扣血或换人。

**光明赐福｜被动技能**：自己回复结束后，受疗者自动获得光明祝福2回合。

**光明祝福｜角色状态**：任何持有者的攻击改为光耀，并在命中附加基础2回合目盲。如果转换前本来就是光耀，则本次伤害穿透光耀抗性与免疫；仅穿透伤害，免疫仍阻止对应魔法状态，抗性仍使附加负面时长−1，格挡也照常−1。原本是其他伤害类型的攻击只转换，不获得穿透。重复获得刷新而不叠加，圣火清除并阻止。固定载荷的太极反弹及知识祝福附属力场伤害沿用自身规则，不作为新的普通攻击转换。

## 生命赐福与生命祝福

生命领域原技能“神佑医者”现名为**生命赐福｜被动技能**：每段治疗前净化，溢出时赋受疗者攻防+1、持续2回合。对应角色状态名为**生命祝福**，不再用技能名代称状态；重复获得刷新，不叠加。角色本身仍因生命修习而为攻−1／防−1。

## 验证与实现位置

规则由`ClericDomains`统一处理回复赐福，`DeathDomainRules`限定死亡／假死加数资格；`AttackContext.ClericBlessings`维护储存快照、光明转换、逐段黎明选择和整次自然反施。黎明复用`WizardChoice`与既有异步续体；角色选择按人物去重，选手直接点战场手牌。

专项见`DeathDomainTests`、`NatureLightDomainTests`与`FeignedDeathTests`；完整功能验证结果见[开发与测试](development.md)。角色技能正文见[技能文案](character-skill-copy-draft.md)，公共防御口径见[格挡定义](combat-defense.md)，完整规则见[RULES](../RULES.md)。历史胜率报告只描述其冻结版本，不代表这三名新领域的当前采样结果。
