# 战斗动画基础设计

2026-10-31。当前交付范围：动作方案、21张可复用透明基础素材（含2张碎盾裁片）和3张手牌状态图标。动画播放控制器尚未接入；本文件规定下一步制作方式。图片由内置 image_gen 绘制，原图、最终提示词与导出清单留在 [素材目录](../Art/Production/combat-animation-v1/README.md)。

## 视觉与定位

沿用黑铁、旧金、手绘材质。武器无底板、无文字、无装饰外框；特效保留半透明边缘。攻击从**本段攻击来源手牌中心**出发，指向**实际承受者角色徽记／生命条附近的受击锚点**，不落在对方某只手上。选择攻击目标时保持手牌可见；动画开始后不将数字改回旧值。若代挡／转移，轨迹改指向实际承受者。

伤害类型决定特效，职业决定载体；取实际类型（含附魔与随机类型），不以角色固定类型代替。范围取攻击开始时的实际座位距离，1以内含1；换位、阵亡、占位物与幽灵均沿用规则层当时结果。

## 动作与载体表

| 伤害／来源 | 素材与基本动作 |
|---|---|
| 挥砍 | `weapon_sword`沿来源至目标弧线挥出，命中前叠`fx_slash`，单次短促斩击 |
| 钝击／圣武士 | `weapon_hammer`举起后向目标砸落，命中叠`fx_impact` |
| 钝击／法师、术士、牧师 | `weapon_staff`向目标挥棍，不默认施放元素 |
| 钝击／武僧 | `weapon_fist`从来源手向目标短促冲拳 |
| 其他钝击 | 默认战锤；后续子职独有武器只替换载体 |
| 穿刺／实际距离≤1 | `weapon_rapier`沿连线直刺，快速回收 |
| 穿刺／实际距离>1 | `weapon_bow`停留来源处拉放，`projectile_arrow`飞向目标；弓本体不飞过去 |
| 魔法伤害／法师、术士、牧师、邪术师、德鲁伊等施法者 | 对应`fx_*`从来源手飞至受击点，保留类型形状与颜色 |
| 魔法伤害／奥法骑士、剑咏者 | 直剑载体加对应元素，元素附着剑锋并在命中点扩散，不换成法术球 |
| 魔法伤害／四象宗 | 拳头载体加对应元素，拳锋与冲击点着色，不换成剑或法术球 |
| 其他角色的魔法攻击 | 默认对应元素投射物，保留后续扩展接口 |

双将优先取本段伤害改写／附魔来源：四象门徒用拳，奥法武器／法术回响用剑；其余元素使用施法载体。不能仅按主将职业判定，否则同一双将交换主副位会改变表现。

## 十种魔法特效

| 类型 | 文件 | 色彩与轮廓 |
|---|---|---|
| 火焰 | `fx_fire` | 橙红火舌、余烬 |
| 寒冷 | `fx_cold` | 冰蓝晶簇、霜雾 |
| 强酸 | `fx_acid` | 黄绿腐蚀液滴 |
| 毒素 | `fx_poison` | 翡翠绿毒雾，与强酸的液体轮廓区分 |
| 闪电 | `fx_lightning` | 电蓝分叉电弧 |
| 雷鸣 | `fx_thunder` | 蓝紫同心声波，不使用闪电轮廓 |
| 力场 | `fx_force` | 绯红几何冲击环 |
| 心灵 | `fx_psychic` | 粉紫眼形念波 |
| 光耀 | `fx_radiant` | 金白放射光束 |
| 暗蚀 | `fx_necrotic` | 紫黑幽雾，与现有暗蚀图标同色系 |

每张特效兼作投射物、剑锋／拳锋附着层及命中扩散层；通过旋转、缩放、透明度做三种用途，不必生成每个职业×每个元素的重复素材。受击闪光用类型色，不把所有类型都染成红色。真实伤害沿用其来源动作，以白色数值和现有说明识别，不新增第十四种伤害类型。

## 基本时间轴

| 阶段 | 建议时长 | 表现 |
|---|---|---|
| 起手 | 0.08秒 | 来源手外侧出现武器或聚能点；不遮数字 |
| 飞行／挥击 | 0.20～0.28秒 | 从来源至目标；远程可延长到0.35秒 |
| 命中 | 0.08秒 | 冲击扩散与受击闪光；命中瞬间展示本段伤害、状态和盾变化 |
| 淡出 | 0.12秒 | 武器／特效消隐，归还对象池 |

一段约0.48～0.56秒；多段逐段播放，相邻段间隔0.06秒。剑士追加、反击、卫护斩、反弹各有独立来源和目标，不合并成一次大掉血。卫护斩使用小型金色冲击脉冲，保持固定2点的现有结算。

## 合盾、碎盾与太极

- 合盾：对应手牌中心显现`Overlay/shield`，0.12秒由0.55倍放大至1.08倍，0.08秒收至1倍，0.18秒淡出；常驻小图标随后保留。4／6合盾同样使用盾图标，数字继续显示4／6。
- 碎盾：命中时完整盾闪亮0.06秒，替换`Overlay/shield_broken`，0.22秒缩放并淡出；使用`shield_fragment_1`与`shield_fragment_2`沿左上／右下散开，无需额外手模。常驻碎盾图标保留。主动以盾运算时，先播放破盾，再播放其后发生的攻击／合盾。
- 代挡：从保护者徽记向原目标显示短促金色联线，随后攻击落点改为保护者。其盾破碎后再播放卫护斩，不在原目标上播放碎盾。
- 太极：`Overlay/taichi`在对应手牌旋转约半圈，承伤与反弹分别按真实结果表现；反弹从太极手指向原攻击者。太极归零即撤去常驻标记。
- 闪避：攻击擦过实际目标，显示现有闪避提示；不播放命中或附加状态。取消：在出手前收散，不播放命中。格挡：播放到达、盾击与碎盾，生命数值依照实际结果。

## Unity 接入约定

资源位于`Resources/Art/Battle/v1/Animation`，可通过`BattleArt.Get("Animation/...")`加载；现有三个状态键`Overlay/shield`、`Overlay/shield_broken`、`Overlay/taichi`已替换，GUID不变。武器／特效512×512，状态图标256×256，Sprite Single、Bilinear、Clamp、关闭MipMap、保留alpha。每张主体统一在画布中心82%以内。素材默认朝本地+X；弓竖直，箭头朝+X。弓和箭不可共用一个移动节点。

武器以独立RectTransform容器做握持轴旋转，建议剑／刺剑握持点为贴图归一化(0.23,0.5)、锤／棍(0.14,0.5)、拳(0.27,0.5)，美术接入时微调；元素层作为武器子节点放在刃尖／拳锋。默认禁用raycastTarget，不拦截任何操作按钮。动画层位于战场上、选择与结果弹窗下；用对象池，支持加速和跳过。旧金特效亮度受控，不遮名字与状态列。

下一步实现应由规则层发出不可变的攻击／盾事件快照：来源玩家与手、实际受击者、类型、载体来源、段索引、距离、命中／闪避／取消、护盾变化、实际掉血和状态变化。不要重跑一次攻击来得到动画数据。攻击选择前运算结果已显示；待所有防御选择完成后按事件顺序表现。若核心先完成结算，表现层须暂存前后显示快照，避免血条先变再补动画。试炼结束按钮与胜负界面须等表现队列清空后出现，返回标题时清空队列。

## 验收要求

1v1／2v2／8人均检查来源手与实际目标；换位、代挡、反弹、追加、多段各检查一次。施法球、附魔剑、元素拳要一眼可分。无有效目标或放弃攻击不产生攻击动画；无效果纯运算只变数字。攻击类型变化与抗性／免疫按真实结算展示，动画不新增伤害或多消耗一次护盾。小尺寸图标须在38像素下可区分完整盾、碎盾和太极。
