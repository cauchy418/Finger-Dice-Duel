## 阅读方式与来源

- **自身策略**：AI如何安排手值、运算、攻击和技能选择。
- **针对策略**：全局针对模型、开局对手修正和少量专属判断。各角色没有一个统一的“针对百分比”。
- **手值权重**：下文每名角色的0～9原始表；权重包含0～9。它不是直接伤害，也不是选招概率。
- **组合／技能分**：满足条件后直接加入评分，与手值缩放系数分开计算。同一走法可叠加多个项目。
- **机制应对提示**：从图鉴摘录给读者参考，不能据此断言AI已实现同等深度的战术规划。

## 1. 公共自身评分与优先级

走法总分由效果档位、角色额外分、运算后手值、组合奖励、下一手潜力、针对惩罚、目标优先级、集火及斩杀等相加。另有难度噪声与控制器先行选择。**自身系数12与针对系数43不代表12∶43，也不保证总决策为7∶3。**

| 项目 | 当前实现／权重 |
|---|---|
| 基础攻击档位 | 4→44；6→66；8→88。部分特殊效果再由角色接口修正；不是按最终实伤统一换算 |
| 合盾 | 50；角色另加技能分 |
| 普通回复 | 满血5；非满血且生命≤4为120；其余30 |
| 留牌偏好 | `((W[运算后手]+W[另一手]) / 10) × H`，先整数除法；H通常12，忍宗1v1为8 |
| 组合奖励 | 每条匹配后直接加完整Bonus，不除10、不乘H；多条匹配可叠加 |
| 下一手潜力 | 无组合规则的角色才计算；枚举留下的手与场上其他存活角色手值，取最佳普通效果分×120÷100。最高88×120÷100=105，代码注释“约10分／千分比”已过时 |
| 小项 | 加数手为完整盾+8；加数数字2再+5。加数本身通常不改变，不表示该盾被打碎 |
| 斩杀 | 预计可斩杀+100000；伤害预览涉及角色增伤、防御、抗性、免疫、易伤、屏障与虚假生命，仍是启发式 |
| 目标优先级 | 己方与队友均可达+10000；目标每少1%生命+100；无盾／太极+100；低防御再按`(10−clamp(防+5,0,10))×10`；攻击威胁加`clamp(攻+5,−10,10)` |
| 多人集火 | Self：优先离自己最近的敌人，同距取低生命，再取小座位；攻击该目标且可达+25000。仅一名敌人时不加 |

## 2. 公共针对模型与模式区别

### L：原情境针对模型

当前针对对象首先取**加数手主人**；加数是自己或队友时直接返回0。任一方生命≤40%才触发。低血攻防分支检查能否行动与射程，强制赌博回合跳过借手针对。令E为自己运算后两手在该对手原始表中的最高权重先乘42÷100；自己危险加一个E，对手危险再加一个E，最终扣`累计E×D÷100`。两种危险使用同一敞口估值，未分别推演“攻击机会”与“防守机会”。

若针对对象具有自加能力，另比较每只留牌与其归一化双手和：每超1点额外扣6，单手最多30；同样只在上述危险分支中生效。这是数值敞口近似，并非证明魔术师能造出所有较小数字。

### P：运算后机会预览模型

遍历全部存活、可行动且非已知队友的角色；用其每只可运算手，分别加自己运算后的两手。对每个结果给分：

| 机会 | 预览分 |
|---|---|
| 结果本身 | 对手原始手值权重÷4 |
| 攻击 | 按可达、合法目标和预估伤害计分。低血每点伤害+8，上限60，常态每点+4，上限32 |
| 合盾 | 对手≤40%生命+45，否则+15 |
| 回复 | 对手缺血且无腐朽：其≤40%生命+50，否则+15 |
| 对手组合 | 每条匹配加`min(40,组合Bonus÷4)` |

取所有敌方机会的最大值，扣`最大机会×D÷100`。常态也计算，不以低血作为开关；它不改状态、不消耗随机数。尚未完整模拟敌方下一回合全部技能、防御、额外攻击和选目标过程。

## 新改技能决策

- 预言：打出7积累不同预兆，已有记录时保留一只7。替换决策比较原结果与候选结果对行动者的收益，对自己／已知队友取正差，对敌人取负差，并扣1点记录成本；收益不大于保留时不发动。不会为无收益的改写耗记录，也不预支尚未记录的数字。
- 忍宗：有盾可拆、每段攻防差有利或气较充裕时才倾向影分身；负攻防差且无盾时保留气。消耗1气，不再免费自动分段。
- 太极：先决定用哪只太极，再按真实攻击者的威胁选择普通化解、1气免伤或全反。低血时优先免伤，能反杀且能承受半伤时倾向全反；每段分别扣气。
- 散打：倒伏／震慑耗1、暗劲耗3；不重复附无收益控制或暗劲。回合初体力等于气时，治疗有用且无腐朽才发动免费混元体。仅自己后续命中能引爆暗劲。
- 四象：按免疫、抗性、已有状态和元素反应选择类型；低血且仅余少量气时会保留防守资源。四象法门可不发动，不会为非五元素购买抗性。
- 醉拳：未醉时优先9，至少2气且无圣火时倾向入醉；醉拳中所有数字攻击，凑同手值补气，回合开始按规则自动耗气／退出。AI不窥看未来1d10或1d5掷骰；统计固定其独立随机源。
- 塑能：待用类型存在时倾向进攻消耗，空储备的低值攻击可铺类型；候选类型考虑目标抗性和反应。待用保护不会误按一次受击消耗。
- 防护：在自己与已知队友中，综合缺血、可达敌人、攻击类型及攻击加成选受保护者；不授给敌人。重新授予时按替换后的威胁估值，不把自己上次赋予的抗性当作永久抗性跳过。仍只选六项合法抗性。
- 龙族按对手元素与伤害联动选择血脉。首次附加按共同规则，再次成功附加已有的同名状态时延长剩余时长1回合。

全体武僧在正常行动后双手相同且未满气时加分：不足2气+40，否则+22；双将也只获得一次资源。预言角色钩子对打出7基础+35，能记录新数时另+35（合计70），持7且有记录+25；用掉唯一7且未留下7时−25。新增项目与已有斩杀、射程、团队、手值和针对评分共同参与，不解释为发动概率。
