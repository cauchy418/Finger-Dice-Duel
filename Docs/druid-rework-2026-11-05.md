# 德鲁伊重构与孢子结社

2026-11-05，当前规则口径。

### 德鲁伊：荒野形态与四结社

职业攻0／防0、距离1、钝击，初始2点荒野充能。回合开始双手和10时，可消耗1点充能并跳过本回合，进入熊／狼／鹰／蛇形态；形态独立血池归零恢复原体力并承受溢伤，自己每个回合结束可解除，不要求双手相同。形态不直接互切，解除不返充能；每局补满，局内仅真菌感染可回充。

月光结社的月之魔力使初始充能+1，枭熊和黑豹仅月光可选，消耗2点。星辰结社的观星修行在选择荒野后再选星耀，两者攻防相加、距离取高、同时解除：射手座+2/−1、距3、光耀覆盖原类型；圣杯座0/0、距1、形态上限+4，正常打出9回复后可额外选择任意存活角色（含自己）回复9；巨龙座+1/+1、距3，回合开始可纯运算，未做则回合结束必须纯运算，无合法加数时略过。巨龙不再连续加两次；纯运算只改手值，不触发数字效果或额外推进回合。进入荒野所跳过的回合不追加巨龙纯运算。

大地结社保留打3附束缚2回合。大地行者改为回合结束双手都没有3时，可选自己一手禁作加数，至自己下回合开始；可不发动，只限制被借数，不妨碍主动运算。

孢子结社为绝对中立。孢子环绕在自己的回合开始，若有孢子生命，对距离1的其他角色附腐朽2回合，不再比较体力。一体共生为主动：双手相同且当前没有孢子生命时，可消耗1充能获得10点孢子生命；无期限，先扣孢子生命、再虚假生命及实际体力，溢伤正常承受，孢子生命存在时攻击改为毒素。真菌感染在相邻其他非召唤角色真正死亡时恢复1充能，最多初始总量；按死亡前的座位与占位物算距离，形态解除不触发，同一死亡只计一次，最后一名对手死亡也可触发。

双德鲁伊初始荒野充能相加，共用一个池；双武僧初始气也相加为4，气上限仍6，同次行动仍最多回1气。双将仍须不同子职、同阵营序列；不因此放宽选角限制。

荒野期间仅形态和星耀能力生效，原角色及另一子职技能暂停；原有状态正常计时。治疗作用于当前形态，原体力不跟随回复。羊改为独立5/5体力；套在荒野外的变羊先结算羊，再结算荒野，最后原形，各层溢伤只传递一次。形态徽记替换战斗面板原徽记，数值与血条显示当前形态；原体力可在徽记说明查询。
