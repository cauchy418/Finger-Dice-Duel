# 抵挡机制与攻击附加负面时长（2026-10-29）

所有由攻击附加的计时负面状态按每段攻击独立计算：最终附加时长=max(0,基础时长−格挡扣减−对应抗性扣减)，格挡和抗性各最多扣1。通常2回合变为：正常2、仅格挡1、仅抗性1、格挡＋抗性0；龙族血脉等3回合基础同样计算。0回合不施加、不刷新，也不移除已存在的同名状态。多段按命中顺序附加／刷新：第一段挡下附1回合，第二段正常命中刷新为2回合。伤害按原分段规则处理，不因记录状态而重复扣血。

普通防御加成、攻击方失能和伤害自然为0不等于格挡。转移、减半、吸收、血池合并为一次格挡扣减；对应抗性独立再扣1。抗性／免疫的消耗时点沿用原规则：整次多段共享临时修正，纯盾挡／闪避不消耗，至少一段落地后统一消耗。

## 附加范围与顺序

本次调整仅涵盖由攻击附加的计时负面效果，包括元素负面状态、元素反应的新增／刷新（如冻结、耳鸣、酸毒互刷），以及技能流血、战斗招式、散打控制、妖魔契约、惑控心智和征服恐慌；基础时长通常2，血脉等按自身基础值。全部按本次攻击的各命中段扣时长；战斗大师仍要求该段实际造成伤害，惑控仍要求该段真实掉血。攻击前选好的控制在命中后附加，闪避／取消不会先挂状态。回合开始、纯运算、换位附魅惑、碎盾后另选角色束缚等独立触发不属于攻击的命中附加，维持自身规则。圣光、剑歌、战恩等角色状态，以及旧日支配者的异界疏离等技能专属效果不扣时长。无回合数的共鸣标记不扣时长，但未命中不附加。

0回合不施加／不刷新同名状态，但不取消该次命中，也不回滚伤害或原有反应的清除动作；对应魔法免疫仍阻止该次反应附加、刷新及清除。每段的时长先独立记录，再按原命中次序应用，以保留整次攻击现有的伤害计算与抗性快照。例：1→2最终2，2→1最终1；0→1最终1；0回合不覆盖既有3回合。

代码：AttackContext.ElementDuration的ElementHit保存段号、格挡原因、抗性、免疫；不复用旧WasBlocked显示标记，因此太极等部分减伤不会被战报误报为“盾挡零伤”。验证见ElementDurationTests与Art/Integration/guard-duration。
