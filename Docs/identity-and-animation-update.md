# 身份规则与角色动画更新

目标：停用忠臣替死，保留扩展接口；按现有真实技能事件补齐过时和遗漏的动画；重新采样八人身份局。

## 实现与验收

- 忠臣不再为主公承受致命攻击，不显示替死待命按钮。`TryLoyalistSacrifice` 与候选人接口保留为空操作；`AttackContext.LethalLoyalistSacrifice` 仍允许独立调用者注入回调。
- 用致命攻击、旧候选人和独立回调测试规则与接口边界。真实主公死亡仍按身份胜负规则处理。
- 动画按当前58个子职的技能与状态核对，使用真实来源、目标、数值和类型；沿用暗色奇幻素材及当前播放器。动画不改变玩法或随机序列。
- 身份局随机选角2000局，再用该轮数据更新偏向选角并独立采样600局。其余模式的数据保留原采样来源，不标成此次新测。
- 完成功能回归、UI编译、动画验收及文档链接检查后，代码、采样与文档分别提交并推送。

## 完成验证

忠臣旧候选人入口不触发替死，独立注入的致命攻击取消回调继续有效。身份专项18项通过；完整功能回归1724项通过、0失败，跳过8项独立统计；241个UI脚本编译通过。统计工具7项校验通过。

本轮随机身份2000局、偏好身份600局已完整跑完；随机组先更新运行时选角偏好，再用独立种子验证偏好组。全部新样本无游戏异常或模拟器强停，平局保留在分母。[胜率报告](../Tools/Statistics/2026-11-11-ai-activation/README.md)明确标出四组沿用数据的原提交和源码指纹。

角色动画按58个子职逐项核对，17个子职需补齐、41个沿用已有入口；新增技能与持续循环共39种定稿变体、78张原生渲染关键帧。详见[覆盖清单](skill-and-status-animation-list.md)及[截图验收](../Art/Integration/skill-animation-rework/README.md)。

技能回复的表现回调在真实回复后、灼伤结算前记录画面；仅用于显示的管理器不启用原本未传入管理器的伤害反应，避免改变古贤互相回复等玩法。狼、圣杯、妖魔、混元体和不灭哨卫均验证了实际回复量、后续灼伤、目标和先后顺序。
