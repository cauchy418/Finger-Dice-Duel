# 青壮年人物立绘

战士7、术士4、法师9、圣武士6个子职，每个子职男女各一张，共52张透明全身原画。人物限定人类、高精灵或半高精灵，外貌约22至32岁；男性采用英俊或刚毅形象，女性采用美丽或飒爽形象。

延续写实绘画质感、黑铁、旧金与低饱和织物。战士以实用甲胄和兵器区分技法；术士以自由衣装与天赋魔力区别于学者；法师以长袍和法杖区分学派，剑咏者兼持直剑和轻法杖；圣武士以誓约纹章、剑盾与庄重甲胄区别于战士。每对子职男女另设发型、轮廓、装备和站姿。

原[战士立绘](../fighter-character-illustrations/README.md)和[术士／法师立绘](../caster-character-illustrations/README.md)按用户要求保留，本目录为另套可选人物原画。尚未替换游戏现有徽记或自动加入立绘界面。
