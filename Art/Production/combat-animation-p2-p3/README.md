# P2／P3专属动画素材

六张透明主体：藤蔓、三环铁链、逸闻书页、五指法师之手、龙族先祖虚影、空白命运骰。由内置image_gen分别绘制；原图、完整提示词与SHA256见[manifest.json](manifest.json)。

导出只做已获授权的透明边界裁切、居中、等比缩放，保留alpha。运行图1024×1024，最长主体820；原图保存在source。运行export.py可复现导出，已有Unity GUID不变。

法师之手已检查为一拇指加四指。骰面无预绘数字，运行时显示本次已经确定的1～9结果；动画不额外掷骰。角色徽记和手型数值模型均沿用原有资源。
