## 数据和兼容

`CharacterProfession` 保存 12 个职业；`CharacterIdentity` 保存 27 个子职中英文与归属。正式 ID 为 `职业_子职`，例如 `rogue_swashbuckler`。`CharacterDefinition.Find`、`CharacterCodex.For` 和 `BattleArt.Get("Classes/旧ID")` 接受旧 ID；旧别名不作为额外角色显示。

代码类型、测试文件与徽记文件同步迁移。枚举顺序不变。原有 `.meta` 随资源原样移动，新增元数据交给编辑器生成。`migration-audit.json` 记录迁移路径；`baseline-mechanics.tsv` 是导入重构前从运行编辑器读取的 27 组基础数值。
