# 术士与法师人物立绘

术士4个子职、法师9个子职，各有男性、女性全身立绘，共26张。沿用[战士立绘](../fighter-character-illustrations/README.md)的暗色奇幻、旧金细节与写实绘画质感；织物、皮革、黑铁法器与局部法术辉光保持统一。

术士以天生魔力、随身信物和自由衣装表现血脉与魔法来源；法师以研究服装、法器与严谨的施法形态表现学派。每对子职男女立绘分别设计年龄、衣装结构、法器和站姿。

## 文件与验收

全部使用内置image_gen逐张绘制为1024×1536 RGBA透明PNG。原始PNG逐字节复制到本目录，保留生成透明通道，未作程序切图、重绘或缩放。人物、手部、鞋靴、法器与武器均按完整构图验收；同时检查26张数量、13组男女配对、透明通道、来源与SHA256。
