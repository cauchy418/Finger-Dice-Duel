# 负面状态图标第三版

2026-10-21。正式资源位于 `Assets/Resources/Art/Battle/v1/Status/`，18 种状态各有独立图标。黑铁底、旧金方框与绘画主体延续第二版。

本轮使用内置 **image_gen** 绘制 9 张：覆霜、流血、潮湿、震慑、跛脚、倒伏、魅惑、失能、眩晕。生成原图保存在 `source/`；完整提示词保存在 `prompts.json`，以工程内原有的冻结手图标为边框和画风参考。眩晕最终重试使用本轮魅惑图作为同风格参考。

原有完整冰封手图改以 `frozen.png` 表示「冻结」；原有精神惊惧图改以 `panic.png` 表示「恐慌」。历史 `freeze.png`、`stun.png` 保留，实际运行通过 Core 的 `StatusNames.IconKeyOf` 指向规范键，避免枚举别名混淆。

用户已授权程序切图、缩放和镜像。本轮只进行透明边裁切、等比缩放和留白；不以程序替代主体绘画。运行 `node Tools/ArtPipeline/export-status-icons.cjs` 可从原图重新导出 512×512 PNG，并检查透明通道、尺寸及 18 张图片的唯一性。全部 `.meta` 由引擎生成。

- `contact-sheet.png`：18 种实际状态总览。
- `small-size-check.png`：28／40／64 像素预览。
- `manifest.json`：中文名、规范资源键、来源与 SHA-256。
- [秘法手册引擎截图与验证记录](../../Integration/front-end/README.md)。

秘法手册分为「伤害类型」「状态一览」「元素反应」三页，加入 18 种状态、持续与刷新规则、6 条元素反应、命中判定及增伤取整。心灵的恐慌／震慑各 50% 仅保留在伤害类型页，不列入元素反应。战斗状态栏与手册使用相同资源键。多人状态条调整为 22 像素、三列六行，容纳全部 18 种状态。
