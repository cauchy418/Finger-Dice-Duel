# 游荡者·诡术师美术

圆形子职徽记以蓝紫色法师之手、旧金钥匙与银色直匕首表现诡术施法。另绘制独立透明法师之手，用于战场第三只储值手与交换动画；两张图均为五指。

| [法师之手](fx_arcane_trickster_hand.png) | [512 PNG](../../../Assets/Resources/Art/Battle/v1/Animation/fx_arcane_trickster_hand.png) | 独立储值面板、持续浮动与交换表现 |

交换时本体手与储值面板之间播放双向数字弧线；储值不是可点击的第三只作战手。变羊、荒野形态及死亡时隐藏，恢复原形保留储值。图像由内置 image_gen 生成，保留透明原图；运行时版本按已授权的程序缩放统一为512×512。完整提示词、来源、哈希与导入记录见[清单](manifest.json)。
