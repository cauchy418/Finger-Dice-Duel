# 绘画版伤害、状态与职业图标 v2

日期：2026-10-20。按用户提供的两张参考重新生成，采用暗色奇幻、旧金装饰边框与具有体积和材质细节的绘画主体。

2026-10-21 更新：绘画图标已接入 1v1 棋盘，详见 [接入与引擎验证](../../Integration/1v1/README.md)。下文保留本批图标的制作记录。

目标为 46 个独立 PNG：13 种伤害、9 种本项目实际负面效果、24 个角色职业徽记。正式资源仍使用 `Assets/Resources/Art/Battle/v1/Damage/`、`Status/`、`Classes/` 原有路径，便于替换与保持资源引用。其他手型、背景、UI 和状态叠层沿用前一批。

## 图集与语义

- Damage：五列三行，最后两格留空；顺序为挥砍、钝击、穿刺、雷鸣、强酸、毒素、光耀、暗蚀、火焰、寒冷、闪电、力场、心灵。
- Status：三列三行，顺序为残响、强酸、中毒、目盲、腐朽、燃烧、冰冻、感电、震慑。参考图中的流血、魅惑、恐惧、沉默、束缚没有替换游戏状态。
- Classes：整张 24 枚生成两次遇到网络错误后，改为三张四列两行的图集，每张 8 枚；总览仍按六列四行显示。顺序与原角色徽记清单一致；使用头盔、武器、法器等象征物，不制作人物立绘。
- 物理伤害主体保持中性钢灰；魔法和状态按工程现有语义色确定主色，绘画允许自然高光与暗部，不把整张彩色绘画强行染成纯色。

## 文件和工具

- `references/`：用户提供的风格参考副本。
- `prompts/`：每组完整生成提示词；使用内置 image_gen，没有使用 CLI/API fallback。
- `source/`：生成原始图集；生成结果需完成语义与裁切检查后才导出。
- `native/`：按用户此前明确授权进行的原尺寸裁切。通过透明通道识别实际边框，必要时拆开仅由尖角相接的图块，避免固定等分切掉金框；没有通过放大补画细节。
- `painted-manifest.json`：正式导出记录，包含原始裁切尺寸、坐标、文件路径与主版本信息。
- 独立 PNG 统一 512×512；若源图单格小于该尺寸，512 文件是统一画布与重采样输出，真实源尺寸在清单中保留。

职业徽记自带旧金圆框，伤害与状态自带旧金方框。UI 使用 Simple Image，`Image.color` 保持白色，不再额外叠加徽记环，也不要用状态主色整体乘色，以免金边和材质一起变色。

已输出 28/40/64 像素检查图。28 像素下以主体轮廓与配色辅助识别，细部纹理明显减少；若要保留本批绘画质感，状态/伤害图标建议至少 40～48 像素，职业徽记建议至少 64 像素。具体布局调整属于后续接入工作，本次没有修改游戏 UI 尺寸。

本次保留所有由引擎生成的 `.meta`，不手工修改。此前的矢量母版继续保留为历史资料；重建工具在发现绘画版清单后会保护 46 张新图，避免被旧版覆盖。

## 重建

```text
node Tools/ArtPipeline/import-painted-icons.cjs
node Tools/ArtPipeline/preview-battle-assets.cjs
node Tools/ArtPipeline/validate-pack.cjs
```

导入脚本读取本目录的五张 source 图集，并在替换前检查全部图集和图块数量。资源仍为素材交付，静态拼装预览不能代替引擎内的实际尺寸、点击与多人布局验证。
