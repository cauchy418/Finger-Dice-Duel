# 五个奥术子职：美术交付

使用内置 `image_gen` 绘制，沿用暗色奇幻、绘画主体、黑铁底与旧金圆框。`generation-manifest.json` 保留每张图的精确提示词和参考图；`sources/` 保存原始透明 PNG，`selected/` 为裁去透明留白并居中的 512×512 PNG。

| 素材 | 定稿内容 |
| --- | --- |
| 变化学派 | 金属立方、流动银与青色晶体之间的物质变化；不以羊为职业主体 |
| 惑控学派 | 紫晶焦点、催眠金环与魔法丝线 |
| 奥法骑士 | 裂盾、直剑与元素火花 |
| 剑咏者 | 两把交叉的直刃双刃剑、蓝金奥术音波；已替换弯刀方案 |
| 咒剑 | 黑色咒刃、紫色宝石与灵魂锁链 |
| 变形状态 | 方框羊形状态图标 |
| 变羊角色 | 原变化学派羊形圆框改作变形角色头像 |
| 咒缚幽灵 | 青绿色幽灵甲胄圆框 |

`node Tools/ArtPipeline/prepare-arcane-five.cjs` 可从项目内原图重新整理全部素材；只做裁边、缩放与居中，未手改 Unity `.meta`。
