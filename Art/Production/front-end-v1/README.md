## 制作方式与来源

- 9 张绘画原图使用内置 **image_gen** 生成，没有使用 CLI/API fallback。
- `prompts/image-prompts.json` 保存完整提示词与参考图角色；`source/` 保存每张原始生成图；`generation-results.json` 保存生成文件来源。
- `references/front-end-concept.png` 是用户参考图副本，只作为风格和布局参考。
- 70 张 UI／工具图标延续工程已有 SVG 体系，保留在 `svg/` 中，可以编辑和重建；这些控件不是 AI 绘画主体的替代品。
- 程序处理限于用户已授权的切图／缩放／画布统一；三个模式图标增加 16px 透明外边距，保留原始透明通道。绘画主体未用程序重画或抠底。
- `.meta` 由引擎生成，不手工编辑。
