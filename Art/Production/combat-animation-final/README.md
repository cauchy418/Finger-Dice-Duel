# 专属动画主体素材

portal_frame：旧金蓝色门户；shadow_monk：武僧完整分身；accursed_specter：咒缚幽灵完整轮廓。

原图及完整生成提示词见[manifest.json](manifest.json)。原图由内置image_gen绘制，导出只做已获授权的透明边界裁切、居中与等比缩放，保留透明度。运行图1024×1024，主体最长边820。

用Python与Pillow运行`export.py`可从项目内保存的原图复现导出，已有Unity GUID保持不变。定稿实际效果见[截图索引](../../Integration/skill-animation-finals/README.md)。
