# 冒险第一关验收（2026-10-24）

第一关「初战 · 边境哨站」已接入主菜单→冒险模式→剧情冒险。全量1192项测试通过、0失败；8项专项包含32组长自由练习采样。Unity条件编译及UI编译通过；实际团结引擎80项检查通过，见[逐项结果](validation.txt)和[重放脚本](review.cs.txt)。

- 从真实按钮进入开场，首次不能跳过；取消返回冒险菜单并丢弃对局。模态期间不能点击手牌或推进AI。
- 点击白名单与高亮同步；走完攻击、还手、合盾、盾挡、回复、满十归一与半自由决胜。生命/手值/盾状态逐步断言。
- 收官士兵持续只做无效果运算，没有安全运算时休整，不再攻击/回血/合盾；休整仅授予本关NPC，不影响普通对局。
- 姓名为边境士兵，徽记复用旧士兵头盔，资源`Adventure/guide_soldier`；未新增可玩角色或生成新美术。
- 引导在左侧，未遮挡四张手牌；文本在面板内。通关要点替代普通“再来一局”弹窗。
- 胜利后可重打/返回冒险菜单；本地通关后才出现自由练习入口，跳过后不重播开场攻击。切回普通1v1无旁白、无休整权限。
- 自动验收恢复原有PlayerPrefs通关状态，不把测试结果存成用户进度。
