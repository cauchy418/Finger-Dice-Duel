## 已复现并修复

奥法骑士主动用完整盾作运算手，选择在实际结算前完成；5＋1算6，本次攻击立即变为所选元素且正常附状态。非攻击结果保留附魔，实际破盾不重复弹窗。玩家和AI均覆盖。

剑歌在回血后消失的原因是控制器先重置行动标记，再结算上一回合结束技能。现先完成旧回合及其选择，再清标记进入新回合；实际回血、合盾、未取消的攻击保留，满血回复和被腐朽阻止的回复不保留。

奉献之誓冲击／援护、生命领域治疗／净化、抗性及其他支持技能按实际队伍选择，保护可覆盖额外及转移攻击；身份局只据公开身份判已知关系。生产AI已开启安全连锁破盾。四人UI过去忽略传入的关系映射，幽灵仍被画成旧座位的敌人，现按实际召唤归属显示队友。

周期掉血按实际来源、类型及免疫后的伤害归因，避免把已免疫的中毒算成流血伤害的来源；虚假生命吸收不误触发实际生命损失技能。
