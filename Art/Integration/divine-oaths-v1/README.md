# 战恩与两个圣武士誓言验收

2026-10-27，团结引擎2022.3.62t15，1920×1080。

## 实现

战争领域−1/−1、∞距离，1内钝击／1外穿刺；回合开始按攻击手数施恩，可选自己、最多两名不同目标，可少选或不选。战恩攻防+1，9可选回复或基础9攻击，支持普通运算／赌博／有效偷窃；2个自身回合，不叠加、刷新。

征服之誓的成长在整次攻击后生效，恐慌以攻击开始时的实际攻防作比较；持普通5／完整盾5／碎盾5均算。自身回合末按是否攻击、是否有5逐层衰减，最低0。复仇之誓开局必选仇敌，受击可转移，仇敌死亡可重选；伤害逐段+1／−1；取消的攻击不落实预选转移。按实际仇敌记录每面破盾来源，包含连锁；额外运算直接点手，仅改数，不推进回合。

手册“状态一览”分20种负面与圣光／剑歌／战恩3种角色状态；仇敌誓言另列角色标记。圣光清剑歌与战恩并阻止重新附加，普通治疗净化保留两者。两个新誓言已经进入职业选角、图鉴、阵营及双将可选池。
