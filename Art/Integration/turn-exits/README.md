# 冻结、跳过回合与放弃攻击验收

2026-10-22。编辑器菜单：`Finger Dice Duel/Preview/Turn Skip and Give Up`。本目录截图均为团结引擎运行时 Canvas 的真实渲染。

## 原因与修复

法师寒冷命中已有覆霜／潮湿的目标会冻结对方，合法运算数变为零。`BoardController.SetupFirstStep` 误把零合法运算设成 `GameOver`，而 `GameManager` 实际没有判定胜负，因此界面弹出「再来一局」，AI 自动跳过的代码却无法执行。双手被锁或暗置也会触发同一个错误。

现在只有真实胜负判定才能结束对局；无合法运算保留在行动入口，人类有跳过按钮，AI 自动执行同一路径。普通跳过与妖术师技能跳过均补齐回合结束结算，冻结在自己的两个回合结束后消退，燃烧、其他状态与距离修正照常处理。冻结时不能借妖术师跳过发动改体力。

震慑不再清空全部运算；它和恐慌等状态通过统一的攻击目标判据过滤。没有可打目标时显示「放弃攻击」，保留计算结果并取消伤害；直接结算的 AI／无头路径也有相同守卫。已进入攻击确认或技能、防守抉择后，不允许用跳过绕过当前操作。

## 覆盖范围

| 场景 | 验证结果 |
|---|---|
| 1v1 人类冻结 | 跳过按钮可见、可点击；手牌不能主动操作；不弹重开 |
| 法师寒冷命中 AI 战士产生冻结 | 完整逻辑回归通过；实际 GameBootstrap.Update 自动跳过 AI 回合并回到玩家 |
| 双手锁定、暗置及混合四种组合 | 跳过按钮可点击，不误判对局结束 |
| 双成型盾 | 可主动跳过，保留盾牌与手值 |
| 一手锁定、一手完整盾 | 不提供跳过，仍须使用可行动的盾 |
| 刺客潜行 | 可主动跳过一次，不可重复使用 |
| 妖术师同命 | 跳过后选择目标生效；状态时长继续递减 |
| 震慑、恐慌施加者为唯一对手、对手潜行 | 放弃攻击按钮可见可点击，保留 4／8 等运算结果、不伤害目标 |
| 2v2 四个座位、8 人八个座位 | 每个本机视角都实际点击冻结跳过与无合法目标放弃按钮 |

未加入普通局面任意跳过的规则；主动跳过仍遵循双盾或角色技能条件。
