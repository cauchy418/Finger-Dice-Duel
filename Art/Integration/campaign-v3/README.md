# 四章剧情接入验收

2026-11-04。设计与背景／徽记先以`94ac6f1`推送，再实现四章40关。现行配置见[设计总案](../../../Docs/Adventure/four-chapter-v3/README.md)。本轮没有重采胜率。

## 实现

- 第一章初战改用重甲战士，20生命、+2/+2、距1挥砍，无特殊技能；实操4+2=6、4−2=2，次战仍为勇士。
- 万象回廊11～20关接入新背景、元素精魂／元素回响；风暴两课、龙族四课、幽影、狂野反应、塑能三相和全部术士子职经典终战。
- 法师高塔21～30关移除塑能课，防护课缩为持续抗性／奥术守御；新增剑咏者入歌、回血维持、攻击维持和满血回复结束四个检查点。
- 残旗战场顺移31～40，保留真实四／八人队伍、援护、转移目标与经典终战。
- 四章菜单、滚动选关、终战职业池、剧情衔接、音乐、稳定ID存档迁移已连接。旧11归新21，不映到新回廊；保留旧章节访问权，新回廊和剑咏课不会获得旧通关。
- 教学末拍等待动画和全部选择结束，中央确认后才整备存活敌方；玩家及同袍正常回复6，保留队伍、座位、技能资源和死亡。实战另计50轮，真正胜负后仍由右侧“试炼结束”打开总结。
- 失败可重新指引或直接恢复本次实战起点；基准是内存纯模型对象图，重试不叠治疗／成长，不携带失败尝试的动画和UI回调。

## 验证

[完整功能回归](regression.txt)：**1601通过、0失败，8项独立统计跳过**。Unity/NUnit条件编译和全部表现层脚本编译通过。

`CampaignV3Tests`七项覆盖：全部35节引导、40关实战与重试、26种终战子职、稳定ID与教学句覆盖、重甲攻防、13次真实元素命中及对应反应、剑歌回血维持、完整状态／座位与委托恢复。普通课进入实战前不授予通关、不自动弹完成；最长反应课30轮，实战有独立50轮预算。

关键修正是先在护卫合法行动中调数、再为其施加冻结前置，避免因冻住后无法调数而把演示算成无效果。眩晕和冻结经过真实受限回合，刻印不提前清掉尚未自然结束的眩晕；耳鸣免雷鸣在下一次刻印时清理，防止第二个雷电反应被免疫。13次命中类型与伤害见回归日志。

[Unity原生校验](validation.txt)116项通过旧存档迁移、四章入口、五节实际界面流程、资源键、中央确认、Mono模型快照和UI直接重试。临时进度键与更新状态在`finally`中恢复；测试不写真实通关。复现脚本为[validate.csx](validate.csx)，通过本机Codely运行；截图使用实际Canvas与RenderTexture，采样状态光效的静止帧，未修改游戏规则。
