# 1v1 技能按钮与居中修正

运行编辑器菜单 `Finger Dice Duel/Preview/UI Alignment and Skills`，在真实运行时界面检查并截图。本目录的 PNG 由引擎渲染，非概念图。

## 改动

- d20 的 1–20 按字体实际可见字形的顶点边界居中，避免 CJK 字体行框把数字压低。
- 图鉴与所有选将共用徽记卡：徽记居于装饰框正中，名称在框下单独一行，使用加粗浅金文字。
- 1v1 的技能操作使用黑铁旧金五态按钮、对应职业的绘画徽记与清楚的操作名称。候选为多只手时直接列出目标按钮；原手牌点击仍然有效。
- 回复、冲击等以角色为目标的技能，左右手代表同一角色，按钮只列一次。战士连锁破盾有多个目标时明确列出盾牌，避免通用发动按钮默认选第一面盾。
- 1v1 技能按钮随抉择者放在上方或下方手牌右侧；按钮多时缩紧间距。多人已共用职业徽记按钮并改用可滚动操作区，见 [多人接入记录](../multiplayer/README.md)。
- 不修改技能触发条件、数值、结算或 AI。刺客双 7 潜行仍由运算触发，出现的是每次潜行可用一次的跳回合操作。

## 验证范围

`validation.txt` 记录字形居中、徽记卡中心与名字间隔、24 种战斗徽记加载、实际技能触发和按钮点击检查。主动技能截图覆盖单 / 多候选、防御抉择、治疗目标、双 9 的两次目标选择、附魔类型与吟游诗人的分步面板。

按钮通过 EventSystem 射线检查和指针点击事件验证，检查画布边界、手牌、提示条、战报和其他技能按钮的遮挡。逻辑回归另用工程无头测试及两种编译检查验证。

2026-10-21：本专项 **748 项**、前台 **638 项**、原 1v1 接入检查 **140 项**、全量逻辑 **979 项**通过；Unity 条件编译、表现层编译与真实编辑器编译均通过。


## 技能提示与战报更新（2026-10-21）

触发提示统一为“角色【技能】操作说明”，保留代价、伤害与目标规则。战报统一为“角色 手别：算式 → 结算结果”；实际生效的主动／被动技能另记“角色【技能】目标与效果”。附魔、元素、状态、闪避、太极、潜行、治疗、破盾、成长和吟游诗人等都在实际生效处登记；不发动、取消点击和 AI 意图不会被记成已发动。回复采用生命实际增量。

圣武士 4／6 在选完加数后直接询问冲击，点击一次冲击目标就完成合盾，不再确认普通攻击目标；8 的攻击仍需选目标；旧盾碎裂与新盾合成两次冲击仍分别询问。覆盖单将与双将，实际点击检查 4、6，截图见 `paladin-shock.png`、`paladin-six-shock.png`、`paladin-history.png`。

本次验证：991 项逻辑测试、762 项技能界面检查、768 项前台检查，以及 Unity 条件编译和 UI 编译检查通过。
