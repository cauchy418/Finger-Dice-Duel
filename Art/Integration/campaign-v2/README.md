## 关键行为

教学后等待待答和动画结算，号角只正常治疗一次，解除护持及脚本，保留当前手值、技能资源、伤势、成长、死人、座位、回合及战报。只有真实获胜写原Level／章节完成键。旧Sample键不再决定新课开局或通关。最后真实一回合结束后先停留战场，点击“试炼结束”才显示结果。

NPC架盾、急救、整军、集结令代替正常行动；冷却只计算其自身回合。四／七课推障改变实际距离。第五课、各章终战无调律、护持或号角。已通关直接自由练习不领补给。
