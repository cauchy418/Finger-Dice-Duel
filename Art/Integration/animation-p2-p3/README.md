截图由Unity原生Canvas与生产播放器的同一个绘制方法输出。WebP采用无损编码，导出逐像素核对与Unity原PNG一致；未后期绘画。总览仅缩放拼接原图。受控姿态样例用于审美、落点和缺图检查，不能混称为一次真实技能操作测试。
