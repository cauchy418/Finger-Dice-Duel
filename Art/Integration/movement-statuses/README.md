# 束缚、油腻与圣光图标验收

2026-10-24～25。新增藤蔓束缚与油腻，状态现为21种，元素反应九条；图标见[制作记录](../../Production/status-icons-v4/README.md)。圣光（用户称圣火）按可见Alpha主体重新裁边、统一448px，保持512px画布与同一UI槽位。

## 规则范围

束缚每次自身行动随机一手不能主动运算，仍可被借作加数，与技能锁独立。重复查询不重选，次回合重选；两手均不可用可跳过，偷窃／赌博不可绕开。净化、到期、重开均清限制。

油腻只在一次完整运算后50%触发倒伏，保留两个后续自身回合；跳过、偷窃、赌博不投，巨龙两加数只投一次。火焰命中清油腻、伤害×1.5并附燃烧；与覆霜／潮湿共存时优先油腻、只增伤一次，其余状态保留。盾挡算命中，闪避／取消不触发，火焰免疫保留油腻并阻止燃烧。

这些是通用状态与施加接口，没有擅自赋予现有角色新的状态技能。
