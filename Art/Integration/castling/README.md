# 王车易位接入验收

2026-10-23。法师·咒法学派保留空间刃，新增可选主动技能「王车易位」。另一名存活角色双手值相同（不分左右），可与其换座并跳过回合。距离立即更新，队伍与身份不变；当轮保持原行动顺序，下一轮采用新座位。

- 「王车易位 · 跳过回合」进入目标选择；每人一项，可点击高亮手牌或目标按钮，取消不耗回合。冻结时只走原跳过流程。
- 多人换位后仍控制原角色，面板、座位号、队友关系按内核刷新。双将主副均可提供技能。
- 额外行动内使用技能不推进正常轮次；状态结算一次。AI 在能减少相邻敌人数时选择换位。
- 修复非攻击偷窃漏记轮次、首位角色被回合开始状态击杀误加轮次的问题。
