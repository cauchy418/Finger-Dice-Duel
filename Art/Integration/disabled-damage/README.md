# 失能与攻防修正验收

失能原先仅清零基础伤害，逐段仍叠加攻击加成和负防御，额外真实伤害也会绕过归零。现在本次攻击的每段及额外真实伤害均保持0，命中、破盾、附加状态照常；光明领域既有固定4规则保持优先。

实际引擎通过41项检查，见[日志](validation.txt)和[复现脚本](review.cs.txt)。包括12项状态测试、23项新子职测试以及真实UI三步攻击：勇士攻+5对塑能学派防−3，伤害为0、目标20生命和8虚假生命均未变化，回合正常结束。

七项新增失能回归覆盖正攻击、负防御、单段／多段、元素和技能附加、护盾、特殊／真实伤害、虚假生命、AI斩杀与未失能对照。另外三项回归保证逸闻／幻术的减伤也覆盖攻防加成，持续状态伤害不消耗这些防御资源。

失能不会免除已经存在的燃烧等持续伤害。妖魔的持续受伤也不会误触自己的妖魔契约或汲取。
