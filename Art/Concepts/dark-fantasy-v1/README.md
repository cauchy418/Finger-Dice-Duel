## 视觉规范

- 背景：炭黑石材 #15181D；框架：黑铁、旧黄铜 #A88A57；文字：暖象牙白。
- 装饰：d20 几何、奥术刻纹、低密度雕刻；手型与操作提示的可读性优先于装饰。
- 角色识别：统一圆形职业徽记，用主轮廓、武器、法器区分。阵营徽章作为独立叠层。
- 可点击为白框，选中为金框；不得仅靠背景颜色表示状态。
- 5 的初始数字、完整盾、碎盾、太极分别表达；暗置仍显示数字。
- 所有语义色沿用 Core 中 AttackDamageTypes / StatusNames；生成图片中的颜色只是近似，正式资产需要匹配。

## 手型优先的战斗界面（v2）

用户新增要求：每个玩家区分左手、右手，每只手具有 0～9 共十个手型，合计 20 个基础手型；手型为主要信息，数字位于手型下方作为辅助。

- 主面板显示大手型，底部独立小字区显示数字和左右手标签，数字不得覆盖手掌或抢占手型主体。

## 正式资源生产与接入

1. 依据样稿确定视觉方向，简化缩小时不可读的细节。
2. 逐个输出透明 PNG：伤害/状态建议 256×256 母版，职业徽记建议 512×512 母版；轮廓保持统一占比。边框、底板和符号分层导出。
3. 按实际 28/32/48/64 像素显示尺寸验收；重点检查暗蚀与闪电对比度、五种施法职业之间的辨识度。
4. 为数字、剩余回合数、名字保留引擎文字，正式 UI 不烘焙这些内容；面板使用可拉伸九宫格资源。
5. 在 UI 层添加 Sprite 资源映射，沿用当前规则键；不要将 Unity 类型引入 Core、Characters、Assistant。保留缺图时程序绘制的回退图标。
6. 导入时由团结引擎生成 .meta，不能手工创建；最终执行工程文档要求的三项检查及 Play 模式视觉验收。
