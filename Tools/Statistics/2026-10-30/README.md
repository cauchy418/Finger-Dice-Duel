# 55子职重新采样（2026-10-30）

采用最终武僧、预兆替换、持续抗性、猎人追加与狂野逐段类型规则；与旧52角色快照分开。总计 **58,476局**，异常／模拟器强停均为0。普通50轮按正式规则结算，真正平局计入分母。

| 模式 | 局数 | 抽样方法 |
|---|---:|---|
| 1v1 | 29,700 | 1,485个不同角色配对各20局，双方各占一半物理先手；每角色1,080次出场 |
| 2v2 | 23,760 | 1,485支双角色队伍，每队与固定偏移742的队伍配16局；每角色1,728次出场 |
| 双将 | 3,816 | 477种合法组合各与固定偏移238的组合配8局；每组合16次出场，双方先手均衡 |
| 八人阵营 | 600 | 单将3/3/2，角色与阵营轴一致；每类阵营各担任2人方200次 |
| 八人身份 | 600 | 随机8个不同子职与隐藏身份，按身份阵线记录胜者；不是偏好选角实验 |

1v1和2v2按胜场／全部出场计，平局不算胜。双将角色值按其组合的结果共同计胜；八人角色阵亡仍按所属阵线计分。固定配桌、共享队友与随机选角限制了泛化，不与旧快照直接作技能强弱因果比较。

```powershell
$env:FDD_REVISION_MODE='1v1'  # 依次换为2v2、dual、eight、identity
powershell -NoProfile -ExecutionPolicy Bypass -File Tools/HeadlessTests/run-tests.ps1 -Only RevisionBalanceTests -OutputDirectory Tools/HeadlessTests/bin/revision-sample
# 每种模式日志保存到 Tools/HeadlessTests/bin/revision-<mode>.log
python Tools/Statistics/summarize-revision.py
```
