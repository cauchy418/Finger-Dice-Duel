## 复现与证据

```powershell
$env:DOTNET_PROCESSOR_COUNT='1'
$env:DOTNET_TieredCompilation='0'
$env:COMPlus_TieredCompilation='0'
$env:FDD_REVISION_ROOT='Tools/Statistics/2026-11-05'

powershell -NoProfile -ExecutionPolicy Bypass -File Tools/HeadlessTests/run-tests.ps1 -Only RevisionBalanceTests -OutputDirectory Tools/HeadlessTests/bin/druid-57-sample
# 各模式日志保存到 Tools/HeadlessTests/bin/druid-57-<mode>.log
python Tools/Statistics/summarize-current.py --date 2026-11-05 --log-prefix Tools/HeadlessTests/bin/druid-57-
```

本轮只测量生产AI，不改角色平衡、权重或技能。未运行全部双将交叉赛、身份偏好选角或集火寻优；旧报告作为历史快照保留。
