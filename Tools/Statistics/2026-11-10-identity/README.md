## 复现与证据

所有模式使用真实BoardController驱动，复用已校正胜者归属的测试台。固定起手、技能及AI随机源，每个CSV保存逐局种子、角色、胜者和行动数。roster.tsv由运行时角色表直接导出；results.json保存五类模式（身份含随机和偏好两组）的逐角色胜／负／平与分母、阵营及身份汇总、源码及CSV指纹；各模式日志均须通过才能汇总。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File Tools/Statistics/run-identity.ps1 -Run -Date 2026-11-10 -Directory 2026-11-10-identity -Baseline <旧轮results.json>
```

58子职共检查10,092个合法起手，见[AI审计](ai-audit.tsv)与[测试日志](regression.log)。

运行器在首局前保存provenance.json，并在每组前后核对游戏源码、测试源码、无头入口及采样工具SHA-256。指纹变化时拒绝拼接不同版本的数据。source_dirty标识采样时存在未提交改动，source_commit与源码指纹共同标识版本。

身份随机组完成后，将identity-roles.tsv逐字节复制到Assets/Resources/Art/Battle/v1/Adventure/identity-role-rates.txt；偏好组使用独立种子。汇总要求运行时表与随机组完全一致，记录identity_preference_sha256。

仅重新生成报告：

```powershell
python Tools/Statistics/summarize-current.py --date 2026-11-10 --directory 2026-11-10-identity --identity-only --refresh-docs
```

本轮运行器仅执行audit、identity、identity-preferred和回归；不会重新执行1v1、2v2、dual、eight。随机身份种子5000000–5001999，偏好身份种子5100000–5100599，与上一轮保持一致。
