# 57子职胜率重新采样（2026-11-06）

采用新版龙族、风暴、奉献、战争及法师技能，并更新防护学派和相关AI，重新采样 **64,768局**。完整样本中的对局异常和模拟器强停均为0。正式轮数上限内的平局计入分母。

| 模式 | 局数 | 抽样方法 |
|---|---:|---|
| 1v1 | 31,920 | 1,596个不同子职配对各20局，双方各占一半物理先手；每角色1,120次出场 |
| 2v2 | 25,536 | 1,596支双角色队伍，与固定偏移798的队伍配16局；每角色1,792次出场 |
| 双将 | 4,112 | 514种合法组合，与固定偏移257的组合配8局；每组合16次出场，双方先手均衡 |
| 八人阵营 | 600 | 单将3/3/2，角色与阵营轴一致；每类阵营各担任2人方200次 |
| 八人身份（随机） | 2,000 | 主公随机8候选，其余各6；从各自候选均匀选一名 |
| 八人身份（偏好） | 600 | 独立种子，同样随机发牌，再按身份内的平滑胜率加权 |

胜率均为胜场／全部出场，平局不算胜。双将子职按其组合共同计胜；八人角色阵亡仍按所属阵线计分。固定配桌和随机选角限制了泛化；旧数据与本次角色池及规则不同，百分点差不能直接归因于某次技能修改。

## 复现与证据

所有模式使用真实BoardController驱动，复用已校正胜者归属的测试台。固定起手、技能及AI随机源，每个CSV保存逐局种子、角色、胜者和行动数。roster.tsv由运行时角色表直接导出；results.json保存所有五模式逐角色胜／负／平与分母、源码及CSV指纹；各模式日志均须通过才能汇总。

```powershell
$env:DOTNET_PROCESSOR_COUNT='1'
$env:DOTNET_TieredCompilation='0'
$env:COMPlus_TieredCompilation='0'
$env:FDD_REVISION_ROOT='Tools/Statistics/2026-11-06-arcane'
$env:FDD_REVISION_MODE='1v1'  # 依次换为2v2、dual、eight、identity
powershell -NoProfile -ExecutionPolicy Bypass -File Tools/HeadlessTests/run-tests.ps1 -Only RevisionBalanceTests -OutputDirectory Tools/HeadlessTests/bin/druid-57-sample
Copy-Item 'Tools/Statistics/2026-11-06-arcane/identity-roles.tsv' 'Assets/Resources/Art/Battle/v1/Adventure/identity-role-rates.txt'
$env:FDD_REVISION_MODE='identity-preferred'
dotnet Tools/HeadlessTests/bin/druid-57-sample/HeadlessTests.dll RevisionBalanceTests
# 各模式日志保存到 Tools/HeadlessTests/bin/arcane-sample-<mode>.log
python Tools/Statistics/summarize-current.py --date 2026-11-06 --directory 2026-11-06-arcane --log-prefix Tools/HeadlessTests/bin/arcane-sample- --arcane
```

身份偏好表按主公、忠臣、反贼、内奸分别计胜／出场，并用同身份总体胜率和24局先验平滑；只对随机分发到该席的候选加权。原始数据见[随机身份分角色](identity-roles.tsv)及[偏好验证分角色](identity-preferred-roles.tsv)。

57子职均检查了自身权重、已有对策以及双方57×57配对的三档起手，共9,747个合法起手检查。逐角色运行时导出见[AI审计](ai-audit.tsv)，功能回归见[测试日志](regression.log)。
